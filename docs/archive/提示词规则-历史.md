## 二、v3.5 的提示词改动（2026-10-23）

**① 情绪不再是数值**

角色属性从四维变三维：`体力 / 理智 / 存在感`。`stat_emotion` 留在库里但**不再进提示词**，
改由角色卡的「当前状态」文字表达，形如 `｜当下「刚被拒绝，强撑着」`。

新增【情绪表演】段，写死三者分工：

> **情绪只定方向；强度定藏露；理智定语量。三者冲突时以强度优先** ——
> 疏离档下，任何情绪都不外放给对象看。

**② 术语定死**（消灭"状态"一词三义）

| 指什么 | 叫法 |
|---|---|
| 关系层面 `稳定/紧张/破裂` | **关系态势** |
| 角色此刻那一行文字 | **当下** |
| 从当下 + 强度 + 理智读出来的方向 | 情绪（**不是字段**） |

尾部块标题也同步改名：`【数值与状态】` → **`【数值与当下】`**。

**③ 心声与台词的关系从"必须相反"改成六种**

| 类型 | 例 |
|---|---|
| 反向（口是心非） | *有事。但我不会说给他听。* |
| 旁支（跑题） | *他袖口上沾了灰。* |
| 自欺（找台阶） | *我只是懒得争，不是在意。* |
| 掐断（说到一半停） | *我本来想说——算了。* |
| 钝（只有身体感） | *耳朵在响。* |
| 算计（盘算利害） | *现在翻脸，吃亏的是我。* |

保留两条边界：疏离/戒备/拒绝越界时，心声必须**与台词同向**；心声不许写成剧情总结或人物点评。

**④ 关系配合度**（把强度翻译成合作意愿）

- 低强度默认拒绝：可拒绝、回避、拖延、谈条件；亲密接触一律先拒；主动配合必须有明确理由
- 硬触发清单：上一轮有肢体伤害且未道歉 / 强度 < 20 且对方提亲密接触 / 台词与身体冲突 → **必须明确拒绝**
- 拒绝之后就停住：不加缓和句、不加"但是"、不加半推半就的动作

**⑤ 数据字典英文化**

关系强度/态势/角色属性的说明改成**英文脚手架**（中文枚举值保留），因为英文指令更容易被模型读成规则；
末尾显式写死「输出必须是简体中文」。

**⑥ 关键记忆注入**（v3.5）

尾部块新增 `【关键记忆】`，位置在 **【世界书】之后、【示例对话】之前**
（先补"她背后的世界"，再提"你们之间发生过什么"，最后才教"她怎么说话"）：

```
【关键记忆】本故事里已经发生、不可重来的事（不要重演第一次；可作为回忆、心结或情绪的来处）
- 第 4 天 · 表白：……
```

数据来自 `<数据根>/library/default/projects/<故事>/memories/*.md`，**按祖先链过滤**，空白则整段不出现：

- **可见性（2026-10-30 改口径）**：`memory::branch_visible` —— 主线（`branch` 为空）的记忆**所有分支都继承**；
  某条分支的记忆，**只有当前分支的祖先链上有它才可见**。祖先链由 `branches.source_branch_id` 一路向上取
  （`ancestors_of`，含自己，防脏数据成环 64 层封顶）。
- 于是：**嵌套分支读得到父分支的承诺**（4 层分支能看到 6 分支第 7 天的承诺）；
  **兄弟分支互不可见**（从同一个分叉点分出去的两条线，各自看不到对方的记忆）；主线只看到共享段。
  注入与界面（时间线页的「🧠 关键记忆」）共用同一个过滤函数。
- **行的样子**：一条一行，`- 第 N 天 · 类型：一句话摘要`（表白卡另有「被拒绝 / 已被接受 + 理由」的拼法）。
  **承诺卡的「待兑现 / 已兑现 / 未兑现」只存在卡片 front matter 和界面徽标里，不进这一行**（2026-10-30 核对）。

**⑦ 日摘要改成「每满 10 条刷新一次」**

同一轮数不重复跑（`summary.rs:109`）。以前是"超过 10 条后每加一条都重算"，白烧 token 且破坏前缀缓存。
