## 四、剧情页（`story`）—— 界面最复杂的一屏

### 4.1 四层结构（2026-10-24 定）

```
标题行（故事名 · 时间起点 · 模型 · 导出 · 返回故事库）        ← 不滚
提示条（✅ 已切到「主线」，右侧 ✕ 关闭）                     ← 不滚（App.tsx:1066）
剧情头部（分支条 + 下一天/插入插曲 + 天数药丸）               ← 不滚（portal 到 App.tsx:1108）
滚动容器（日摘要 + 消息）                                     ← 只有这里滚（App.tsx:1110）
```

**固定头部不是 sticky**：它是 `StoryPanel` 用 `createPortal` 挂到 App 里一个**常驻宿主 div** 上的
（`StoryPanel.tsx:260`）。sticky 只是"在容器内贴顶"，仍会随内容上移、还会被标题行盖住。

### 4.2 剧情头部（`StoryPanel.tsx` + `DayStrip.tsx`）

| 区块 | 说明 | 锚点 |
|---|---|---|
| 分支切换条 | **始终显示**（只有主线时也只有一项）；改名 / 备注 / 删除都在这里，点它们**不得触发**"切换分支" | `StoryPanel.tsx:170–243` |
| 下一天 / 插入事件 / 插入插曲 | `+ 下一天` / `⏳ 插入事件` / `🎭 插入插曲`，右对齐。`⏳ 插入事件` 用 `lib/timelineDates.ts::pickGap()` 找空白期：有 → 开 `InsertEventModal`；没有 → 提示"时间是连续的，直接用「+ 下一天」" | `:271–279` |
| 天数药丸横条 | `DayStrip`：这条线的天（父链顺序，含共享历史），**左右滑动**；点某天只切节点、不切分支；进对话区与**每次切分支**都滚到末尾 | `DayStrip.tsx:24` |

### 4.3 滚动区（`StoryPanel.tsx` 下半）

| 区块 | 说明 | 锚点 |
|---|---|---|
| 日摘要 | 当前这天的日摘要；生成一次即固化，没有就提示可生成 / 重新生成 | `:268` |
| 消息气泡 | 旁白 / 台词 / 动作三种渲染；导演指令作为独立小条显示在气泡上方，正文里不重复 | `:326` |
| 删除 | 只在「我」的消息上给入口，按「我 + 紧随的 AI 回复」**成组删除** | `:306` |

### 4.4 输入台（`StoryInput.tsx`）

| 控件 | 说明 | 锚点 |
|---|---|---|
| 旁白 / 对话 | 两态切换；**导演指令 chips 只在对话模式可用**，一次性生效 | `:121–122` |
| 我扮演 / AI 扮演 | 对话模式下的下拉，默认男主 / 女主；无对应定位时保持「自由」 | `:126/131` |
| 长度 | 下拉框，**向上展开**（2026-10-18 用户要求） | `:182` |
| 🔍 回顾 | RAG ①：手动指定某一天，直接把它拼进提示词 | `:224` |
| 提示位置 | **不在这里**了：提示条统一在页面层级（标题行下、滚动容器外），输入台没有再挂浮层 | 见 §4.1 |
| ⏹ 停止 | 生成中才出现，带 requestId 调 `cancel_generation` | `:293` |
| 敏感词 / 记忆开关 · 剧情约束 | 实装；敏感词表内置常开、可扩 | `:178/222` |
| 发送 | 解析 → 生成 → 保存到当前节点（Enter 发送） | — |

## 九、维护规矩

1. **本文的"锚点"必须能在代码里搜到**。改代码时顺手改锚点，或者直接删掉那一行。
2. **不要写规划中的组件名**。规划放 `ROADMAP §二`，这里只写已实装的。
3. **新增 view**：同时更新 `ViewName` 联合类型、`App.tsx` 渲染分支、本文件 §二。
4. **术语统一**：设定侧叫「设定版本」，调试侧叫「请求记录」——**没有"快照"这个词了**（v2.23 改名）。
