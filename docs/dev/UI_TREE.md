## 四、剧情页（`story`）—— 界面最复杂的一屏

### 4.1 四层结构（2026-10-24 定）

```
标题行（故事名 · 时间起点 · 模型 · 导出 · 返回故事库）        ← 不滚（App.tsx:1060）
剧情头部宿主 div（分支条 + 下一天/插入插曲 + 天数药丸）       ← 不滚（App.tsx:1087，portal 目标；常驻、不带 view 条件）
滚动容器（日摘要 + 消息）                                     ← 只有这里滚（App.tsx:1089）
输入台 + 提示浮层（绝对定位在输入框上方 20px）                ← 不滚（StoryInput.tsx:148）
```

**固定头部不是 sticky**：它是 `StoryPanel` 用 `createPortal` 挂到 App 里一个**常驻宿主 div** 上的
（`StoryPanel.tsx:319`；宿主 `App.tsx:1087`）。sticky 只是"在容器内贴顶"，仍会随内容上移、还会被标题行盖住。

> **提示浮层不在头部**（2026-10-25 用户明确要求改回）：它是 `StoryInput` 里 `position: absolute; bottom: calc(100% + 20px)`
> 的一层，`pointerEvents: none`，**不参与布局** —— 出现过/消失都不会把上面的固定头部顶下去。
> （v3.5.5 曾改成"标题行下面一条 bar"，它会占竖向空间、头部跟着上下跳，被用户否掉。）

### 4.2 剧情头部（`StoryPanel.tsx` + `DayStrip.tsx`）

| 区块 | 说明 | 锚点 |
|---|---|---|
| 分支切换条 | **始终显示**（只有主线时也只有一项）；改名 / 备注 / 删除都在这里，点它们**不得触发**"切换分支" | `StoryPanel.tsx:222–276` |
| 下一天 / 删除这一天 / 插入事件 | `+ 下一天` / `⏳ 插入事件` / `🗑 删除第 N 天`，右对齐。`⏳ 插入事件` 用 `lib/timelineDates.ts::pickGap()` 找空白期：有 → 开 `InsertEventModal`；没有 → 提示"时间是连续的，直接用「+ 下一天」"。`🗑 删除第 N 天` 是 v3.6 补回的唯一删除入口（旧的"天数药丸上的 ×"已撤） | `:279–300` |
| 天数药丸横条 | `DayStrip`：这条线的天（父链顺序），**左右滑动**；点某天只切节点、不切分支；进对话区与**每次切分支**都滚到末尾。**共享历史只到分叉点为止**（`branchPathIds`，分叉之后的主线天不出现 —— 2026-10-26 修）；主线灰、分支用分支色；分叉点带 ★、分支的第一颗带 ▸（`lineName · 起点`）；滚动到末尾的逻辑在 `:56–63` | `DayStrip.tsx:26` |
