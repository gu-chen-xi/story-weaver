## 四、剧情页（`story`）—— 界面最复杂的一屏

### 4.1 消息区（`StoryPanel.tsx`）

| 区块 | 说明 | 锚点 |
|---|---|---|
| 分支切换条 | **始终显示**（只有主线时也只有一项）；改名 / 备注 / 删除都在这里，点击它们不得触发"切换分支" | `StoryPanel.tsx:173–243` |
| 时间维操作区 | 「时间维（点「时间流逝」可在空白期插入事件）」与操作按钮合并成一行 | `:259` |
| 日摘要 | 当前这天的日摘要；生成一次即固化，没有就提示可生成 / 重新生成 | `:273` |
| 消息气泡 | 旁白 / 台词 / 动作三种渲染；导演指令作为独立小条显示在气泡上方，正文里不重复 | `:324` |
| 删除 | 只在「我」的消息上给入口，按「我 + 紧随的 AI 回复」**成组删除** | `:308` |
| 时间流逝分隔 | 相邻天数节点之间若跳号 → 内联一条"时间流逝"分隔，点它插入事件（不建空节点） | `TimelinePage.tsx:302` |

### 4.2 输入台（`StoryInput.tsx`）

| 控件 | 说明 | 锚点 |
|---|---|---|
| 旁白 / 对话 | 两态切换；**导演指令 chips 只在对话模式可用**，一次性生效 | `:107–110` |
| 我扮演 / AI 扮演 | 对话模式下的下拉，默认男主 / 女主；无对应定位时保持「自由」 | `:112–117` |
| 长度 | 下拉框，**向上展开**（2026-10-18 用户要求） | `:168` |
| 🔍 回顾 | RAG ①：手动指定某一天，直接把它拼进提示词 | `:210` |
| 提示位置 | 校验/生成中的提示渲染在**输入框旁边**，不是滚动区顶部 | `:278` |
| ⏹ 停止 | 生成中才出现，带 requestId 调 `cancel_generation` | `:288` |
| 敏感词 / 记忆开关 · 剧情约束 | 实装；敏感词表内置常开、可扩 | — |
| 发送 | 解析 → 生成 → 保存到当前节点（Enter 发送） | — |

## 七、其它页面要点

| 页面 | 关键结构 |
|---|---|
| `params` | 四页签：`📊 Token 预算` / `🧾 Prompt 预览` / `🎨 立绘参数` / `JSON`（`ParamsPage.tsx:109`）；预算页显示"上下文窗口 × 系数"的分配 |
| `portrait` | 四视图 `grid / list / masonry / group`（`:46`）；详情是**页内状态** `pDetail`，不是独立路由；支持来源筛选（全部 / 手工 / AI 生成） |
| `timeline` | 阶段摘要"攒够 x 天再压"（`x` 可调）+ 树状图调试视图（默认收起，有分叉才显示控件） |
| `plugins` | 卡片由 `PLUGIN_REGISTRY`（`constants.ts`）驱动：`canToggle` 管"是否自动跑"，手动执行与查看历史不受开关限制 |
| `compliance` | 使用者义务、必须声明、AI 生成标识说明；未同意当前条款版本时左栏显示红点 |
| `chars`（v3.4） | 角色卡 v2 五字段：**过去 / 动机 / 目的 / 行为准则 / 对话示例**（前四项进 system【角色】段，对话示例进尾部【示例对话】，仅焦点角色） |
| `world`（v3.4） | 页签：`📚 设定条目` / `🗺 地图与地点` / `🏛 势力矩阵` / `📖 术语词典` / `🎒 物品库` / `📖 世界书` / 冲突检测；物品全量注入，世界书**触发式**注入 |
| `stories`（v3.3） | 新建表单含**前史/序章**（可空）；故事卡片上可再编辑，进 system 的【前史】段 |
| `timeline`（v3.5） | 页底挂 `KeyMemories.tsx`（179 行）：🧠 关键记忆面板 —— 列表 / 改正文 / 删误记 / 一键导出（`key-memories/<故事>_<时间戳>/`）。**没有「新建」入口**（由系统从剧情提炼） |
| `chars`（v3.5） | 角色表单新增**外貌**（与过去/动机/目的/行为准则同级，约 300 字截断，**AI 不可改**）；属性条从四维变三维（体力/理智/存在感），情绪改由「当前状态」文字表达 |
| `devtools`（仅 DEV） | 五页签：`🔧 概览` / `💉 数据注入` / `🩺 数据体检` / 造样例数据 / `🔍 回顾试算`（与导演监视器共用同一个组件，固定指向所选测试故事） |
