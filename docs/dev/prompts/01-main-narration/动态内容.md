# 动态内容（旁白）

> 最后核对：2026-11-14（按代码逐段核对）｜ 上游：[`README.md`](README.md)

「动态」= 每一轮都可能变的段。规则和预算见 [`../common/预算与裁剪.md`](../common/预算与裁剪.md)。

## 1. 历史（最近 3 天原文 + 更早的摘要）

| 步骤 | 做什么 | 代码：`文件::符号` |
|---|---|---|
| 取天数链 | 找当前节点及其之前的 `KEEP_DAYS` 个天数节点（插曲/倒叙不算天数） | `generate_stream.rs`（历史装配段） |
| 按父链校正 | 用**父链**确定"近 3 天"，避免分支串味 | 同上 |
| 每日条数 N | 由预算倒推（见预算文档） | `generate_stream.rs::plan_day_limits` |
| 更早的摘要 | 日摘要 → 阶段摘要合并 → 按预算裁剪 | `timeline::list_phase_summaries_in`、`coalesce_with_phases` |
| 剥协议标记 | `strip_director` → `strip_receipt` → `strip_marker` → `strip_line` | 见 `../common/协议标记清单.md` |

> 用户这一轮的输入**已经先入库**了；装配时会拿"剥过标记的正文"比对末尾，避免把同一条输入追加两遍。

## 2. 世界书（触发式）

- 触发文本 = **本次输入 + 最近 3 条消息**（上下文一起看，避免"上一句提到、这一句没提"漏掉）。
- 命中规则：`world::lore_hit()`（关键词 / `always`）。
- 排序：`priority` 降序，同优先级按 id；超 1200 字整条跳过并计数 `lore_skipped`。

## 3. 关键记忆

- 取卡：当前分支的祖先链（`memory::list_for_ancestors_in`）；
- 过滤：`filter_for_role(mems, scope.role)` —— 旁白传空 role → **全量**；
- 渲染：一行一卡、1200 字预算（细节见 `../common/记忆块渲染.md`）。

## 4. 示例对话

- 选人：`prompt::pick_example_owner(focus, ai, panel_focus, names)`（三级回落）；
- 渲染：`prompt::examples_block(raw)`；
- 都不满足 → **整段不出现**（宁可没有，也不把 A 的语气套给 B）。

## 5. 数值与当下

- 角色属性：焦点角色优先，否则最多 8 个（附"其余 N 个角色略"）；
- 台词口径：`characters::perf_directive()` 只在三维不正常时给；
- 关系强度：一行一个方向（旁白**全部方向**；对话只留 `from=她`）。

## 6. 导演指令与代价

- 指令原文来自用户输入（`relations::DIRECTOR_TAG`），进尾部 `【导演指令】` + 图例；
- 有指令才要求写收据（`director::cost_legend()`），**平时不要求**，否则每轮都会多一行协议。

## 7. 视角开关

`prompt.roleplay_scope` **对旁白无效** —— 旁白永远 `PromptScope::default()`。
