# 已知坑与测试（旁白）

> 最后核对：2026-11-14 ｜ 上游：[`README.md`](README.md)

## 踩过的坑（别重犯）

| 坑 | 症状 | 现在的处理 |
|---|---|---|
| 协议标记留在历史里 | 模型每轮都写 `〔态度:…〕`，甚至编表外值（`〔态度:冷淡〕`） | 历史装配时四道 `strip_*`（见 `../common/协议标记清单.md`） |
| 同一条输入进两次 | 请求里出现两条一模一样的 `user` | 装配时拿"剥过标记的正文"比对末尾 |
| 示例对话"消失" | 用户没 `@角色` 就整段没了 | `pick_example_owner` 三级回落（focus → ai_role → panel） |
| 记忆挤爆预算 | 卡片多了把历史挤没 | 1200 字上限 + 装不下整卡跳过 |
| 世界书查不到 | 占位符编号与 bind 顺序写错 → 主线永远空 | 查询抽到 `world::fetch_lore_entries()` |
| 前缀缓存失效 | 把"今天第几天"写进 `system` | 时间基准只放锚点与换算规则，当前天数在尾部 |

## 测试在哪

| 目的 | 测试 |
|---|---|
| 预算 / N 值 / 装配顺序 | `cargo test --lib generate_stream`（`budget_tests`、`phase_recap_tests` 等） |
| 双池装配（含旁白那侧全量） | `generate_stream/pair_prompt_tests.rs` |
| 记忆/关系/属性过滤 | `memory::group_tests`、`memory::multi_participant_tests`、`tail_view_tests` |
| 世界书命中 | `world` 模块内测试 |

## 手工验证

1. 开发者工具 →「请求快照」→ 选一条 `mode=narr`：看 `system_prompt` 的段顺序与 `tail_block` 的段；
2. 生成参数 →「双池对比」：旁白那栏应显示**全部**角色卡与全部关系方向；
3. 若两栏一样且提示"没记录扮演者" —— 那是正常的（旁白本来就该等于全局）。

## 什么时候必须回来更新本组文档

- 改 `build_system_prompt` / `build_tail_block` 的段顺序或条件；
- 新增一种协议标记（同时更新 `../common/协议标记清单.md`）；
- 改预算常量或降级顺序（同时更新 `../common/预算与裁剪.md`）。
