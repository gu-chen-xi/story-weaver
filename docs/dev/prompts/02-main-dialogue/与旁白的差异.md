# 与旁白的差异（对话 vs 旁白）

> 最后核对：2026-11-14（按代码逐段核对）｜ 上游：[`README.md`](README.md)

## 一句话

同一个装配函数，**只换三样东西**：进 `PromptScope` 之后
「角色卡只留她、关系只留她出发的方向、历史只留这一对的」；
另外尾部三块（属性 / 强度 / 示例 / 记忆）也跟着收窄。**规则、字典、世界观、前史、协议段全部不变。**

## 差异总表

| 维度 | 旁白 | 对话（角色视角） | 影响 |
|---|---|---|---|
| 角色卡 | 全部 | 仅 AI 扮演的那一张 | 主要省字来源 |
| 【你对面的他】 | 无 | 有（名字/年龄/性别/身份） | 让她知道"对面是谁"的最小认知 |
| 关系图谱 | 全部方向 | 仅 `from = 她` | 别人对她的态度不给她（隐私） |
| 关系强度（尾部） | 全部方向 | 仅 `from = 她` | 同上 |
| 角色属性（尾部） | 焦点优先 / 最多 8 人 | 仅她自己 | 不能看到别人的体力/理智 |
| 示例对话 | 三级回落 | 仅认她 | 不给别人语气 |
| 关键记忆 | 全量 | 含她的 + 无归属 | 组归属见记忆文档 |
| 历史 | 近 3 天全部 | 近 3 天里她这一对的 | 老消息（无标记）两边都可见 |
| 开关 | 不受影响 | 受 `prompt.roleplay_scope` 控制 | 写 `global` 一行回退 |

## 不变的部分（别误改）

- ①~⑥、⑨~⑪：**逐字节相同**（`pair_prompt_tests` 里断言"通用段一致"的基础）；
- 尾部 9~17（聚焦 / 约束 / 时空 / 导演指令 / 表态 / 承诺 / 状态变化 / 章目标）：两种模式都保留 ——
  **对账协议不是"旁白专属"**，删了会让对话里"导演代价"没法结账。

## 想验证"到底差在哪"

1. 生成参数 →「双池对比」→ 上半"有差异的段"应是 ⑦/⑧/⑫；
2. 下半"尾部"应是 关系强度 / 角色属性 / 示例对话 三块；
3. 第③段（记忆）按关系组显示 —— 这一对没有卡时会写"有才显示"。

## 易混淆的两个概念

| 概念 | 键 | 用在哪 |
|---|---|---|
| **角色视角**（历史/属性/示例/记忆的过滤） | 单角色 `scope.role` | 真正发给模型的提示词 |
| **配对分组**（记忆按 a×b 分组展示） | 两个角色的集合 | 只在双池对比的第③段给人看 |
