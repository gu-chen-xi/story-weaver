# 已知坑与测试（对话 / 角色视角）

> 最后核对：2026-11-14 ｜ 上游：[`README.md`](README.md)

## 踩过的坑

| 坑 | 症状 | 现在的处理 |
|---|---|---|
| 「自由」被当成角色名 | 角色卡被筛成空，提示词只剩规则 | `PromptScope` 判定前先当"未指定"处理（空 / 自由 → 不筛） |
| 关系只按单向读 | 她只知道自己对别人、看不到别人对自己的｜**这是设计**，不是 bug | 反向行属于隐私，只给她出发的方向 |
| 老消息全部"看不见" | 换视角后历史像被清空 | 无 `meta` 标记的老消息 = **全局兜底可见** |
| 换扮演者后历史"消失" | 用户以为丢档 | 换配对 = 换视角；界面弹 `lib/roleHint.ts` 提示，旧对话仍在库里 |
| 表白卡没有归属 | 双池对比第③段里看不到它 | 已修：`confession_front` 现在写 `characters:`（老卡不追溯） |
| 记忆按配对分组 ≠ 过滤 | 以为"分组"就是"只给这一对" | 过滤按**单角色**；分组只在预览里给人看 |

## 手工验收（改完这组必跑）

1. 选好「我扮演 / AI 扮演」→ 生成参数 → 双池对比 → 确认 ⑦/⑧/⑫ 有差异、其余段一致；
2. 发一轮对话 → 开发者工具 → 请求快照：`system_prompt` 里应只有她一张卡；
3. 切到「自由」→ 对比页应提示"没记录扮演者"（两栏一样）；
4. 切入一个 5+ 天的老故事 → 历史里老消息仍可见（兜底生效）。

## 什么时候回来更新

- 改 `PromptScope` 的语义（比如以后支持"多角色同场"）；
- 改 `visible_in_role_view` 的判定顺序；
- 改记忆归属口径（单值/多值/参与者的定义）。
