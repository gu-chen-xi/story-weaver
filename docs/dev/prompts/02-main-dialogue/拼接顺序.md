## 历史

| 规则 | 旁白 | 对话 |
|---|---|---|
| 保留范围 | 近 3 天全部消息 | 近 3 天里 **`visible_in_role_view` 为真**的消息 |

判定顺序（`timeline/message.rs::visible_in_role_view`）：

1. `mode = "narr"`（旁白消息）→ **可见**；
2. 消息 `meta` 里没有 `ai_role`/`my_role`（老消息）→ **可见**（全局兜底）；
3. 有标记 → **配对相同或互换**才可见；
4. 当前 `my_role` 为空（界面选「自由」）→ 退回**按角色**判（她出现在任一侧即可见）。
