# 拼接顺序（伏笔扫描）

> 最后核对：2026-11-14（按代码逐段核对）｜ 上游：[`README.md`](README.md)

## 请求结构

```
[system]   扫描提示词（见 ../本地vs云端.md）
[user]     【前情摘要】…（窗口内更早几天的日摘要）
           【本批章节原文】…（本批覆盖的天，已剥标记）
```

## 窗口怎么算

| 步骤 | 规则 | 代码 |
|---|---|---|
| 本批 | 用户指定的那几章 / 那几天 | `lib.rs::scan_foreshadow_local` / `scan_foreshadow_cloud`（批大小由 `lib.rs::local_scan_rounds` 给） |
| 前情 | **本批覆盖的天 + 往前 3 天**（不再喂全部日摘要） | `foreshadow.rs::context_window` |
| 首屏 | 本批是开头几天时前面没有前情，只给本批 | 同上 |

## 输入前先"洗"一遍

`lib.rs::strip_for_scan()` 依次剥掉五类标记：
`relations::strip_director` → `memory::strip_marker` → `director::strip_receipt`
→ `stat_change::strip_line` → `promise::strip_line`。

**为什么**：这些行是软件协议，模型会把 `〔伏笔〕` 和 `〔态度〕` 混着写；洗干净再扫，命中更准。

## 产出与落库

| 步骤 | 行为 |
|---|---|
| 解析 | 逐行认 `〔伏笔〕<东西或话题>` |
| 过滤 | 含人名 / 代词 / 问号 / 省略号 / 引号 → 判为台词或心声，**丢弃**（`foreshadow.rs` 的 `is_*` 一族） |
| 去重 | 与已有伏笔同名的跳过（`scan_proposals_in` 内比对） |
| 落库 | 写 `foreshadows` 表（`planted_chapter_id` 可空 → 章序按 0） |
| 逾期 | `foreshadow.rs::is_overdue(planted, planted_chapter, current_chapter, window=3)` |
| 语义扫描的"跨批候选" | `accumulate_prev_found(prev, seen, cap=10)`（去重 + 只留最近 10 条） |

## 两种失败提示（写清楚，免得用户以为没反应）

| 情况 | 提示 |
|---|---|
| 没勾「扫描伏笔走本地」 | 「还没勾…（插件页 → Ollama 面板）」 |
| 本地服务没起来 | `ollama::probe` 失败 → 报连接错误，**不自动切云端** |
| 云端没配 Key | 报缺 Key，不静默为空结果 |
