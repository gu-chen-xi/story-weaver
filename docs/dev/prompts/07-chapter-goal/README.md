# 章目标注入（不调模型）

> 受众：开发者 ｜ 状态：现行 ｜ **最后核对：2026-11-14（按代码逐段核对）**

## 一句话

这一格**只做注入**：把"当天所属章节的目标"追加到主生成尾部块末尾。
生成大纲/章目标本身不在这里（由人在剧本章节页写，或由别处的生成入口产出）。

## 代码入口

| 职责 | 代码：`文件::符号` |
|---|---|
| 开关（故事级配置 `outline.inject`，默认开） | `outline.rs::inject_enabled` |
| 找当天属于哪一章 | `outline.rs::chapter_for_node` |
| 拼这一小段 | `outline.rs::goal_block` |
| 追加到尾部 | `generate_stream.rs`（`tail_block` 之后 `format!("{}\n{}", …)`） |

## 注入长什么样

在尾部块**最末尾**追加一段，形如：

```
【本章目标】<章节目标原文>
```

| 条件 | 行为 |
|---|---|
| `outline.inject = false` | 整段不出现（零 token） |
| 当天不属于任何章 | 整段不出现 |
| 章目标为空 | 整段不出现（`goal_block` 返回 `None`） |

## 为什么放尾部而不是 system

章目标会随"当前处在第几章"变化 —— 放 `system` 会让前缀缓存失效（每换一章整段前缀重算）。
放尾部后，它只在变化的当天多花几十 token。

## 与主生成的关系

- 旁白 / 对话**都会注入**（它是对账协议的一部分，不是旁白专属）；
- 它不进历史（只在本轮尾部出现一次），也不参与角色视角过滤。

## 验收

1. 把某天挂到一个有目标的章下 → 生成一次 → 请求快照的 `tail_block` 末尾应能看到 `【本章目标】`；
2. 把 `outline.inject` 关掉 → 同一轮不应出现该段；
3. 未归章的天 → 不出现。

## 什么时候回来更新

- 改 `goal_block` 的措辞或格式；
- 改"当天属于哪一章"的判定（`chapter_for_node`）。
