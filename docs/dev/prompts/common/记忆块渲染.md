# 记忆块渲染（跨场景共用）

> 受众：开发者 ｜ 状态：现行 ｜ 最后核对：2026-11-18（按代码逐段核对；这一轮加了"按角色名"与 `ai_side`）

## 一句话

关键记忆对模型只呈现**每卡一行**（不是整张卡），因为尾部预算只有 **1200 字**；
完整正文只在「🧠 记忆」弹窗里给人看。**两边都用人名**，不用 `[用户]/[AI]`（2026-11-18）。

## 代码位置

| 职责 | 代码：`文件::符号` |
|---|---|
| 渲染成提示词文本 | `memory.rs::render_block_for()`（`render_block()` 是"允许改判出口"的默认版） |
| 取卡片（按分支祖先链） | `memory.rs::list_for_ancestors_in()` + `memory.rs::ancestors_of()` |
| 按角色过滤 | `memory.rs::filter_for_role()` |
| 按关系组切 | `memory.rs::group_by_participants()` / `memory.rs::cards_of_pair()` |
| 卡片解析（front matter） | `memory.rs::parse_memory()` |
| **两侧名字** | `memory.rs::ai_name_of()` / `memory.rs::user_name_of()` / `memory.rs::sides_of()` |
| **正文转人名** | `memory.rs::body_for_view()`（读）、`memory.rs::names_for_write()`（写） |
| **告白误判闸门** | `memory.rs::accept_ai_confession()` ← `day_close.rs` / `summary.rs` 调用 |

## 渲染规则

| 类型 | 一行长什么样 | 特别的点 |
|---|---|---|
| 表白 `confession` | `- 第 N 天 · 表白：顾宸熙向夏婉琴表白，被拒绝（共 2 次表白，其中被拒 2 次）；夏婉琴的话：「别。」` | 方向来自 `characters` + `ai_side`；**拿不到一对名字**就退回旧口径（`被拒绝`，不写方向）。理由过滤后为空就不写这半句 |
| 她的告白 `ai_confession` | 直接给她的原话（`夏婉琴：我喜欢你`） | 让模型知道"她已经说过一次" |
| 承诺 `promise` | `- 第 N 天 · 承诺：顾宸熙：我答应你，明天回来。` | 允许多条，各自带状态 |
| 其余（牺牲 / 背叛） | `- 第 N 天 · 类型：顾宸熙：…` | 每类只记第一次 |

> 正文摘要里行首的 `[名字]` 会被换成 `名字：`（`prompt_summary`）—— 只动标签，不改写句子。

## 人名口径（2026-11-18）

- **写卡时**就把行首 `[用户]/[AI]` 换成人名，同时记 `ai_side: 夏婉琴`（写卡时 AI 演的是谁）。
  所以新卡的正文**本来就是人名**，读时转换是 no-op。
- **表白卡摘要行写方向**：`顾宸熙第 1 次向夏婉琴表白：**已被接受**（此前被拒 0 次）`；
  **她的告白卡**：`夏婉琴向顾宸熙告白：原话`（日结 / 日摘要两条路同口径）。
- **老卡**没有 `ai_side`：只有**恰好两个**参与者时才按 `characters` 顺序推断（顺序是 `[AI, 用户]`）；
  一个参与者 / 空 → 不猜，正文保持 `[用户]/[AI]`（全局卡也一样）。
  老卡的 `第 N 次表白：` 由**读时**兜底改写成带方向的句子（文件一个字不动）。
- **只动标签**：正文里的「我」「你」是模型/作者原话，改了一定改坏台词。
- 为什么必须有 `ai_side`：`[用户]/[AI]` 是"当轮谁在操作"的标签，**换扮演者后同一张卡的"用户"
  会指到另一个人身上** —— 承诺/牺牲/背叛的摘要直接进提示词，方向一反就是假记忆。

## 两个开关

1. **`allow_flip_hint`**（`render_block_for` 第三个参数）：表白轮不给"改判出口" ——
   那一轮尾部末尾已经有 `stance_hint`，同一轮教两次会让模型写两行一样的标记。
   决定权在 `generate_stream.rs`：`stance_kind.is_none()` 时才允许。
2. **角色/配对过滤**：`filter_for_role(mems, role)` 只留「含该角色」+「无归属（全局兜底）」。
   归属来自 front matter 的 `characters:`（多参与者，逗号分隔；老卡的单值 `character:` 也认）。

## 预算与降级

- 总预算 **1200 字**，按"重要度 + 创建时间"排序依次填，装不下的整卡跳过（不截半张卡）。
- 装不下时模型会看到"更早的几次不在这里，需要时用回顾"这类提示 —— 由渲染器负责措辞。

## 常见误解

- ❌「记忆页看到什么，模型就看到什么」→ 不是。模型只有一行；正文（含"最近一次"对话）不进提示词。
- ❌「记忆按角色过滤就是按配对过滤」→ 不是。过滤按**单角色**；「按配对」只用于双池对比的**分组展示**。
- ❌「换个扮演者不会影响这张卡」→ 会。所以 2026-11-18 起有了 `ai_side` 与写卡时的名字归一。
