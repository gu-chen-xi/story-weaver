# 记忆块渲染（跨场景共用）

> 受众：开发者 ｜ 状态：现行 ｜ 最后核对：2026-11-14（按代码逐段核对）

## 一句话

关键记忆对模型只呈现**每卡一行**（不是整张卡），因为尾部预算只有 **1200 字**；
完整正文只在「关键记忆」页面给人看。

## 代码位置

| 职责 | 代码：`文件::符号` |
|---|---|
| 渲染成提示词文本 | `memory.rs::render_block_for()`（`render_block()` 是"允许改判出口"的默认版） |
| 取卡片（按分支祖先链） | `memory.rs::list_for_ancestors_in()` + `memory.rs::ancestors_of()` |
| 按角色过滤 | `memory.rs::filter_for_role()` |
| 按关系组切 | `memory.rs::group_by_participants()` / `memory.rs::cards_of_pair()` |
| 卡片解析（front matter） | `memory.rs::parse_memory()` |

## 渲染规则

| 类型 | 一行长什么样 | 特别的点 |
|---|---|---|
| 表白 `confession` | `- 第 N 天 · 表白：第 M 天已接受（不要再演第一次表白）` | 被拒时写"被拒绝"+ 对方理由（**过滤后为空就不写这半句**）；没有 `stance` 的老卡会从正文重算一次 |
| 她的告白 `ai_confession` | 直接给她的原话 | 让模型知道"她已经说过一次" |
| 承诺 `promise` | 带状态（待兑现 / 已兑现 / 未兑现） | 允许多条 |
| 其余（牺牲 / 背叛） | `- 第 N 天 · 类型：正文摘要` | 每类只记第一次 |

## 两个开关

1. **`allow_flip_hint`**（`render_block_for` 第三个参数）：表白轮不给"改判出口" ——
   那一轮尾部末尾已经有 `stance_hint`，同一轮教两次会让模型写两行一样的标记。
   决定权在 `generate_stream.rs`：`stance_kind.is_none()` 时才允许。
2. **角色/配对过滤**：`filter_for_role(mems, role)` 只留「含该角色」+「无归属（全局兜底）」。
   归属来自 front matter 的 `characters:`（多参与者，逗号分隔；老卡的单值 `character:` 也认）。

## 预算与降级

- 总预算 **1200 字**，按"重要度 + 创建时间"排序依次填，装不下的整卡跳过（不截半张卡）。
- 装不下时模型会看到"更早的几次不在这里，需要时用回顾"这类提示 —— 由渲染器负责措辞。

## 常见误解

- ❌「记忆页看到什么，模型就看到什么」→ 不是。模型只有一行；正文（含"最近一次"对话）不进提示词。
- ❌「记忆按角色过滤就是按配对过滤」→ 不是。过滤按**单角色**；「按配对」只用于双池对比的**分组展示**。
