## 1. 技术栈（已锁定，别换）

| 层 | 技术 |
|---|---|
| 桌面壳 | **Tauri 2**（Rust） |
| 前端 | **React 19 + TypeScript**，Vite 8 构建，**全部内联样式** |
| 状态管理 | **只用 `useState` / 自定义 hook**，不引入状态库 |
| 数据库 | **SQLite + sqlx**（`library.db` + 每故事 `story.db`） |
| 网络 | `reqwest` + `tokio`（流式 SSE） |
| Key | `keyring` → Windows 凭据管理器 |
| 图片 | `image` + `png` crate |

**明确不要引入**（都评估过并否决了）：

| 它 | 为什么不要 |
|---|---|
| Tailwind CSS | 内联样式已经统一，混两套只会更乱 |
| Zustand / Redux | 状态集中在 `App.tsx` + hooks，够用 |
| tiktoken-rs | 体积大；现有"字符粗估 + 自适应降 N"够用 |
| Electron | 早期原型，已废弃 |
| vitest | 本机 npm 装不上；已用 `node:test` 替代（见 §5） |
| 任何 CSS-in-JS 库 | 同上，内联样式是既定风格 |

## 2. 目录约定

```
src\                前端（App.tsx 只放顶层状态 + 跨页逻辑）
  views\            每个页面/面板一个文件（25 个）
  plugins\          插件系统：types / config / host / PluginCard / registry / builtin/<id>/（见 PLUGINS.md）
  hooks\            10 个：useStorySession / useGeneration / useCheckPatch / usePlugins /
                    useTimelineView / useAppSettings / useStoryInputPrefs / useCompliance /
                    usePortraits / useTempFiles
  lib\              纯函数（可单测；不 import React）
src-tauri\src\      后端，按领域一个文件（branch / generate_stream / evolution …）
tests\              前端测试（.cjs，只测 src/lib）
scripts\            工具脚本（含 selfcheck）
docs\               文档，入口 docs\README.md
```

**硬约束**：

- `App.tsx` 行数受 `frontend_guard.rs` 守卫（当前上限 **1300**，实际 1248，**只许往下调**）
- `src/lib/**` 里**不许有运行时 React 依赖** —— 它要能在 `node:test` 里跑（`import type` 可以，编译期会被擦掉）
- 新页面必须：加 `ViewName` 联合类型 → 加 `App.tsx` 渲染分支 → 更新 `UI_TREE.md`

## 3. Git 流程

**身份**（仓库级已配好，别改）

```
user.name  = gu-chen-xi
user.email = gu-chen-xi@users.noreply.github.com
```

**远端**：`origin` → `https://github.com/gu-chen-xi/story-weaver.git`

**提交信息格式**

```
type(scope): 中文描述

refactor(app): 抽出导演监视器面板到 views/DirectorPanel.tsx
docs(pitfalls): 错误合集成文 —— 30 条坑位
fix(db): 回滚包进事务
```

- `type`：`feat` / `fix` / `refactor` / `docs` / `chore` / `test` / `perf`
- `scope` 可省，但**有就写**（模块名，小写）
- 一条提交只做一件事；正文说清"为什么"，不要只写"改了什么"

**铁律**

1. **提交前**：先 `git status` 确认改动范围，向用户报**摘要 + 拟用提交信息**，等确认再提交
2. **`git push` 前必须单独提醒用户并取得同意**：报清 remote、分支、将推的提交、有没有 force
3. `--force` / `--force-with-lease` / 删远端分支 / 改已推历史 → 一律先问
4. 本地 commit / branch / stash 可以正常做，但要在回话里说清楚

## 4. 常用命令

```powershell
cd D:\project\ai生成

# 开发
npm run tauri dev          # 开发模式（前端热更新 + Rust 后端）
npm run build              # tsc + vite build
npx tsc --noEmit           # 只做类型检查

# 测试（两条，全绿才算过；项数以命令输出为准）
npm test                                   # 前端纯逻辑
cd src-tauri; cargo test --lib              # Rust（另含一批 `#[ignore]` 诊断/live 用例）

# 排查"打不开"
.\scripts\selfcheck\selfcheck.cmd           # 启动自检，退出码 0=可用（项数看输出「结论」行）

# 启动（本地脚本，不入库）
.\start.cmd
```

> `start.cmd` **不在仓库里**（`.gitignore` 已排除）：它写死了本机路径与
> `DREAMWEAVER_DATA_DIR`。手写等价物见 [README §七](../../README.md)。

**为什么自检工具必须存在**：这类故障（窗口没建出来、日志插件写不进、连错 dev 服务器）
**全是静默的** —— 进程活着、无 panic、日志停在中途，`cargo test` 一个都抓不到。
它测"函数对不对"，不测"这个 exe 在这台机器上能不能跑"。

## 5. 测试约定

**Rust**：`cargo test --lib`，用例名 `模块::测试组::用例名`。
涉及 schema 的改动**必须有"从空库建起"的测试**（老库早迁移过，测不出全新安装崩）。

**前端**：`npm test` → `scripts/test-frontend.mjs` 把 `src/lib/**` 用 tsc 编成 CommonJS
到 `.tmp/fe-tests/`，再用 `node --test` 跑 `tests/*.test.cjs`。

- 为什么不用 vitest：本机 npm 网络不通（`ECONNRESET`），改用 Node 自带 `node:test`，**零新依赖**
- 测试文件写 `.cjs` 纯 JS（不需要 `@types/node`）
- **什么时候必须补**：改 `src/lib/` 的纯函数（解析 / 预算 / 格式化）时 ——
  这类错误在界面上表现得很隐蔽（气泡分块错、token 数字不对），靠眼睛很难发现

详见 [测试用例.md](测试用例.md)。
