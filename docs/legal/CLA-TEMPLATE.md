## 1. 定义

- **"作者"**：gu-chen-xi（织梦机 / Story-Weaver 项目的版权人），及其继承人、受让人。
- **"贡献"**：你以任何方式提交给本项目的代码、文档、素材、补丁及其修改，包括 PR、patch、issue 中的代码片段、邮件等。
- **"你"**：提交贡献的自然人或法人。

## 2. 版权许可（你保留版权）

你授予作者一项**非独占、永久、不可撤销、全球范围、免费、可再许可（sublicensable）、可转让**的版权许可，允许作者：

1. 复制、修改、改编、合并、发布、分发、公开传播你的贡献；
2. 将你的贡献用于**商业目的**；
3. 将你的贡献**再许可**给第三方，或随本项目**更换许可协议**（包括商业许可、双许可）；
4. 将上述权利转让给作者指定的主体（例如作者设立的公司）。

你**保留**贡献的版权；本协议不构成版权转让。

## 3. 专利许可

对于你的贡献中你拥有或有权许可的专利，你授予作者及本项目的下游使用者一项**非独占、永久、不可撤销、全球范围、免费**的专利许可，允许制造、使用、销售、许诺销售、进口及以其他方式利用该贡献。

如果你或你的关联方就本项目（或本项目包含你贡献的部分）向作者或下游使用者提起专利诉讼，本协议授予你的专利许可自起诉之日起终止。

## 4. 你的声明与保证

你向作者声明并保证：

1. 你有权授予本协议第 2、3 条的权利；
2. 贡献是你的原创，或你已获得足够的授权提交；
3. 贡献不包含第三方的保密信息、侵权内容或违反任何协议的内容；
4. 如果你的雇主对贡献享有权利，你已获得雇主授权；
5. 你已阅读并同意本协议。

## 5. 作者没有义务

作者**没有义务**合并、使用、署名、付费或维护你的贡献；可以随时移除。合并不代表雇佣、合伙、代理或成为维护者。

## 6. 人身权

在适用法律允许的最大范围内，你同意不因作者及其被许可方使用、修改、再许可贡献而主张人身权（包括署名权、保护作品完整权等）妨碍上述许可的实施。

作者会在合理范围内尊重你的署名意愿，但**不承担强制署名义务**。

> 注：中国法下著作人身权不可转让；本条实际效力需律师按具体情形调整，必要时改为"同意不以人身权妨碍许可"的约定。

## 7. 生效与记录

本协议可通过下列任一方式生效：

- 在 PR/issue 中勾选"同意 CLA"；
- 签署本文件（电子签名或扫描件）；
- 邮件或其他书面方式确认。

GitHub 用户名、时间戳、commit SHA、勾选记录等电子记录可作为签署证据。

## 8. 适用法律与争议解决

本协议适用**中华人民共和国法律**。争议先友好协商；协商不成，提交作者所在地有管辖权的人民法院。
