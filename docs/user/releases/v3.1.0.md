# 织梦机 · Story-Weaver v3.1.0

> Windows 桌面 AI 剧情创作工具 · 本地优先（数据只在你电脑上）· 无服务端
>
> **本版本没有代码签名。** 首次运行如遇 Windows SmartScreen「未知发布者」提示，
> 点「更多信息」→「仍要运行」即可；原因与自证方法见下方「关于代码签名」。

---

## 新增

**记忆与上下文**
- **阶段摘要**：攒够若干天日摘要后自动压缩成一段（`x` = 一段覆盖几天，可跨空档），导演监视器可查看 / 删除 / 手动重压 / 清理重叠
- **【时间基准】**：把故事起点日期注入提示词（第 1 天 = 某年某月某日），模型换算季节、节日不再瞎猜
- **回顾检索权重可配 + 「🔍 回顾试算」**：输入一句话就能看到「会带哪几天、多少分、为什么」，8 项权重可调、失焦即存
- 「🧩 上下文概览」：一屏看出本次装配（用量 / 前情提要几天几段 / 时间基准 / 历史 / 回顾注入）

**可用性**
- 对话区**自动跟随滚动**：发送后视图贴住 AI 回复底部；一滚滚轮立即停手，不打搅回看历史
- 消息**成组删除**：以「我 + 紧随的 AI 回复」为一轮删除（AI 回复可能多条；永远不动下一轮）
- 输入框：`📏 长度` 改为**向上展开**的下拉框、`记忆上下文` 精简为 `记忆`、去掉 `Enter 发送` 提示
- 设置 → **数据管理**：存储概览 + 调试记录 / 日志 / 孤儿目录 / 旧备份 / 临时文件的安全清理（调试记录默认上限 300 条，每次生成前自动裁）

**打包**
- 应用图标「蓝色大肥鱼（AI 鲸灵）」，产出 **MSI 安装包** + **免安装便携版**

## 修复

- **P0：全新安装后新建故事必崩**（`no such column: branch_id / parent_id`）——
  根因是新建故事库时漏跑迁移且先登记了连接池缓存，导致新库永远缺列。
  已补「建表后立即跑全部迁移」并加**从空库建起**的回归测试
- 回顾检索**标签词被重复计分**、**角色名被当成标签词**（改 `tag_word` 会连带改名字的分）——
  改为显式类别（标签词 / 实体 / 角色名各用各的权重），并补两条回归测试（含证伪）
- 「单条均 token」加入 **400 下限**：短样本不再把每日 N 值算成几百条
- 剧情页顶部**重复的「生成日摘要」按钮**合并为一个
- 导出时间与 SQLite `localtime` 口径统一；删除硬编码的 `+8h`

三个**可被你自己验证**的事实：

1. **不启动任何外部程序** —— 源码里 `Command::new` 命中 0 次
2. **不驻留** —— 不写注册表自启、不装服务、不建计划任务，关窗即退出
3. **出站只有两类** —— 你在设置里填的模型 API、你配的绘图服务；没有统计 / 埋点 / 上报域名

> 诚实提示：不要用"自己编译的 exe 哈希"对比发布包 —— Rust/Tauri 产物含构建时间与绝对路径，
> 换台机器必然不同。要验「源码 = 二进制」请比**行为**（抓包 + 看写入路径），不要比字节。
