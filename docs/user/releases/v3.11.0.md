# v3.11.0 — 故事终于有「章」了，伏笔和承诺也各自有了账

> 发布 **2026-10-30** · 上一版 [v3.10.0](https://github.com/gu-chen-xi/story-weaver/blob/v3.11.0/docs/user/releases/v3.10.0.md)
>
> 这一版的主题是「**从"一天一天地写"到"一章一章地看"**」：
> 已经写好的「天」第一次能被圈成「章」，于是进度、字数、伏笔、承诺都能挂到章上；
> 伏笔有了台账（手标 + 规则扫描提议），承诺有了三态结算（待兑现 / 已兑现 / 未兑现），
> 而记忆的可见性改成按**祖先链**继承 —— 父分支埋的承诺，子分支读得到了。
>
> 一句话说完：**以前它只会"接着写"，现在它能告诉你"写到哪了、还欠着什么"。**

---

## 一、历史章节：把已经写好的「天」圈成「章」

**以前**：剧情是一天一天存的，写了几十天之后，你自己也说不清"第 3 章写到哪天了"。

**现在**：左栏多了「📖 历史章节」页。章是**你手动圈**的 —— 把若干「天」圈进一章，软件负责统计和展示。

几条定死的规则：

| 规则 | 说明 |
|---|---|
| **多对多，但一天只属一章** | 同一天可以出现在很多地方吗？不。把它归进新章时，**自动从旧章摘掉**（独占） |
| **章序按分支各自编号** | 主线有 1、2、3，分支也从 1 开始；建/删章后**归一化成 1..n**，不会留「01、03」的跳号 |
| **字数不冗余存储** | 按这章关联的「天」里的消息字符现算 —— 你改一句台词，字数跟着变 |
| **删章不删剧情** | 章只是"圈选"，删掉章，那些天还在，回到「未归章」 |
| **建章后回读自检** | 新建完会读一次库核对条款，不符合就把传参问题指出来（而不是静默成功） |

「＋ 新建章」对话框里**多选圈天**，已经属于别的章的天会标上「第 N 章」提示你重复，
并且**只列当前分支的天**（含共享历史）—— 别的分支的「第 2 天」不会混进来。底部常驻一句「还有 N 天没归章」。

## 二、两种看法：卡片墙 / 状态看板

同一份数据，两种视角，顶部切换：

- **卡片墙（A）**：章号当水印，一行幕、两行梗概，底下挂字数 / 天数 / 状态 / 有没有目标，三个动作「打开 · 编辑 · 删」。
  「打开」直接跳到剧情区这一章的第一天。
- **状态看板（F）**：草稿 / 修订中 / 已定稿三列，**点卡片推进状态**（不做拖拽 —— 拖拽在这个体量上只会增加误操作）。

顶部四张**统计卡**，回答"写到哪了"：

| 卡 | 口径 |
|---|---|
| 完成进度 | 已定稿章数 / 总章数 |
| 累计字数 | 所有归章的天里的消息字符（**另含目标字数**，看得见还差多少） |
| 未归章 | 有剧情但还没圈进任何章的天数 |
| 伏笔 | 总数，**含逾期**（`×N` 标出来） |

> **没做的**：原型里的「历史版本 / AI 生成占比」被**丢弃**了 —— 没有章快照、消息也没有来源标记，
> 拿"AI 百分百生成"去算占比没有比较意义 —— **「占比」这条永远不做**（要算得给 `messages` 加来源列再回填全部老数据，
> 成本高于收益），见 [ROADMAP §2.2](https://github.com/gu-chen-xi/story-weaver/blob/v3.11.0/docs/dev/ROADMAP.md)。
> 「历史版本 + diff」要真做得先加章版本表，这是下一版的事。

## 三、按章导出全书

「📚 导出全书」把整本故事按章拼成一份文件（md / txt）：

- **章标题当标题**（`## 第 N 章 标题`），章内**不再出现**「第 N 天」这类日记式分隔；
- **未归章的天收在末尾**，单列一段「【未归章】」—— 口径是"不丢内容"，宁可难看也不吞稿；
- 文件末尾带 **AI 生成声明**（和按天导出同一套法规声明；以前只有按天导出带）。

---

## 四、本章目标：一句话，默认开，空目标零 token

每章可以写一句「本章目标」（比如"让她答应同行，但先付出代价"）。

- **默认开**（`outline.inject`），想要关掉写 `false` / `0` / `off`；
- **没写目标就一个字都不加** —— 空目标不产生任何注入，不占预算；
- 注入块里**不含数字**（不写"第 3000 字要达到什么"这种会诱导水文的东西），只给方向；
- 一章对应多天时，取**章序最小**的那一章的目标（多对多的兜底口径）。

章卡上有「编辑」：标题 / 幕 / 章序 / 梗概 / 本章目标 / 目标字数 / 状态，一次改完。

## 五、伏笔台账：手标 + 规则扫描提议，逾期现算

**以前**：伏笔这种东西只存在于你的脑子里，写到第 20 天早就忘了第 3 天埋过什么。

**现在**：「历史章节」页底部是伏笔区，两种来源：

1. **手标** —— 你自己写一句「她说三年后会回来」，选埋在哪个章；
2. **规则扫描提议**（零 API 成本，纯本地规则）—— 从**已归章的天摘要**里找两类强信号：
   **约定/承诺**（"答应""会回来""等我"）与**明确没说完/没解释**（"没有解释""没说为什么"）。
   一条摘要最多取 3 句、一次最多提 5 条，同一句（含已被拒绝的）不重复提。

状态机是 `提议 → 埋下 → 已回收`，另有 `废弃`：

- 提议可以**接受**（转成"埋下"）或**拒绝**（标 `dropped`，以后不再拿同一句烦你）；
- **逾期只对"已埋下"的算**：`当前最大章序 − 埋下章序 > 窗口章数`（默认 **3** 章）；
- 逾期**不落库**，每次现算 —— 你加了一章、改了窗口，逾期状态自动跟着变，不会留一个僵掉的标记。

> 已知边界：扫描器只认"摘要里的句子"，**不做语义推理**；它宁可漏，也不乱提（提议是可拒绝的，但烦人也是成本）。

## 六、承诺结算：三态徽标 + 记下是谁判的

「关键记忆」里的承诺卡，以前只有"有 / 没有"。现在每条承诺**各自带状态**：

| 状态 | 含义 |
|---|---|
| **待兑现** | 新提炼出来的默认状态 |
| **已兑现** | 剧情里兑现了，或者你自己标的 |
| **未兑现** | **正式状态**，不是"作废" —— 之后真兑现了可以再改回来 |

- 模型可以在回复末尾写 `〔承诺〕兑现` / `〔承诺〕未兑现` 来结算；这两种写法都认，**只剥整行**，正文不动。
- 记忆卡上有**三态徽标**，点一下就切（手改 = `manual` 来源，和模型判的 `model` 分开记）。
- 允许多条并存 —— 一个人可以同时欠好几件事，不再"只记第一次"。
- 没有「待兑现」的承诺时，**不注入兑现协议**（零 token）。

**判定也变严了**（v2）：否定句、威胁、转述、条件句**都不算承诺**。
以前"她说不会答应你任何事"会被记成一条承诺 —— 现在四道排除会把它拦掉。

## 七、记忆可见性：按「祖先链」继承

**这是一个真 bug**：关键记忆的可见性以前是"分支 ID 精确相等"，
于是**在子分支里读不到父分支埋的承诺**（它们是父分支记的，branch_id 不同）。

现在改成**祖先链**：

- 记忆的分支在当前分支的祖先链上 → **可见**；
- 兄弟分支之间 → **互不可见**（各写各的，不串味）；
- 主线是共享段，所有分支都看得到主线上的记忆。

注入与界面用的是**同一套判据**（一个纯函数），所以"界面上看得到"和"模型看得到"不会打脸。

## 八、导演代价会衰减了

以前导演代价是**只涨不落**的账：攒到 60 分锁住导演指令，只能靠人工「撤销 / 赦免」解套。

现在**按故事日衰减**：每满 **10 个故事日**，旧账 **−5 分**，最低 **0**。

- 是**读取时现算**，不是改库里的数 —— 所以账本里那条原始记录、时间、理由都还在，撤销/赦免照旧；
- 换句话说：作过的死会过去，但你作过的死**不会消失**。

```
第 0 天记 20 分 → 第 9 天仍是 20 → 第 10 天 15 → 第 20 天 10 → 第 30 天 5 → 第 40 天 0
```

## 九、顺手修的（都是实测踩到的）

| 问题 | 修法 |
|---|---|
| 章序跳号（01、03） | 章序改成按 `branch_id` 取 MAX，建立/删除后归一化成 1..n |
| 新建章对话框列出**所有分支**的天 | 改成只列当前分支（与剧情区、新建分支同一逻辑） |
| 章节页的提示跑到**剧情对话区** | 改走右下角 **T1 toast**（那里是给"操作结果"留的位） |
| 关系图谱双向关系只有单向线 | 反向那条画**虚线**，并按**法向偏移**错开，不与正向线重合 |
| 世界观「AI 补全」按钮点了没意义 | **删掉**（按"没有消费者就别留"的原则） |

### 发版前又抓到两个洞（打包装箱前修掉）

写文档的时候顺手核代码，发现两处"功能看起来能用、其实是坏的"，都在这一版里修了：

| 洞 | 症状 | 修法 |
|---|---|---|
| **手标伏笔一入库就标红「逾期」** | 手标只填一句话、不选章 → 章序记 0；而逾期公式是「最大章序 − 0 > 窗口(3)」，所以你的故事一超过 3 章，刚写下的伏笔立刻显示「逾期」 | 逾期多一个前提：**知道埋在哪一章才判**（`planted_order > 0`）—— "不知道埋在哪" 不等于 "逾期"。代价是手标伏笔不会自动逾期，要按章判得先在界面选「埋在哪章」 |
| **`〔承诺:未兑现〕` 那行剥不掉** | 模型如果写成带冒号的形状，软件能认出来并结算，但**那行字会留在正文 / 历史 / 导出里**（只认 `〔承诺〕` 这一种） | 两种写法统一按前缀 `〔承诺` 判，跟"认得出"用同一套判据；补了回归测试，顺带确认正文里提到"承诺"两个字不会被误删 |

> 这两个都是**代码**问题、不是文档问题；修完重打了包，所以你现在下载到的 exe 里已经含修复。

### 安全加固：三个用户能感知的变化（发布前同晚做的第二轮）

这一版发布前做了一轮安全审计（静态 + 动态实测，攻击者模型：恶意模型服务端 / 恶意导入文件 / 同机低权限进程 /
本地绘图服务被冒充 / 网络中间人）。**没有找到"远程直接打穿"的洞**，但抓到三个该修的，都在这一版里修了 ——
其中三条会改变你看到的行为：

| 变化 | 说什么 | 为什么会遇到 |
|---|---|---|
| **云端出图：图片地址要过准入** | 图片 URL 跟你在配置里填的地址**同源** → 照旧下载、照旧带鉴权；**不同源** → 只接受 `https` + 公网，且**不带任何凭证**；本机 / 内网 / 链路本地地址一律拒（同源除外） | 那个 URL 是**服务端在响应里给的**，旧版给什么拉什么、还把你的 Key 一起带过去 —— 恶意服务能拿它去扫你内网、或者白拿 Key |
| **确认提案：过期就拒绝** | 提案排队期间那条数据被别人改过 → 确认时会提示「提案已过期」，**不再覆盖**中间改动 | 旧版只把新值写进去、不核对旧值，等于"你点了确认，中间谁改的都被抹掉"，审计里记的"改前值"也是假的 |
| **启动失败：不再一闪即没** | 第二个实例 / WebView2 配置目录被占用 → 弹「织梦机 · 启动失败」并写 `startup-error.log`，然后退出 | 旧版在窗口建失败时直接 panic，而那一刻对话框插件还没注册 —— 用户什么都看不到 |

另有一次"看不见"的加固：云端图片下载的 32MB 上限原来**先全量读进内存再检查**（等于没有事前限制），
现在先看 `Content-Length`、再用**流式累计**，超限即中止。

**已知代价**：如果你的图床在**另一个域名**且**要求鉴权**，现在会 401（跨源不带凭证）。
加一个显式白名单配置键（`portrait.cloud_download_hosts`）才是正解，**本期没做**，记在 ROADMAP §2.1。

> 完整的静态发现、动态复现和修复记录：[docs/dev/安全审计-2026-10-30.md](https://github.com/gu-chen-xi/story-weaver/blob/v3.11.0/docs/dev/安全审计-2026-10-30.md)

## 十、内部（用户看不到的）

- **新模块**：`chapters.rs`（章 / 章节点 / 导出 / 归一化）、`outline.rs`（本章目标注入）、`foreshadow.rs`（伏笔台账 + 规则扫描）；
  `memory.rs` 加了承诺三态与祖先链可见性；`director.rs` 加了 `decayed_score`。都带单测。
- **新表**：`chapters`、`chapter_nodes`、`foreshadows` —— `story.db` 18 → **21 张**；
  两个库合计 **23 张**（`library.db` 3 张 + `story.db` 21 张，`configs` 两边各有一张、按名字只算一次）；
  带 `branch_id` 的 14 → **16 张**（`chapter_nodes` 属于章的从属关系，不单独带分支列）。
  老库启动时自动建表，**不需要你动手**。
- **测试**：Rust **472** 项（**452** 常跑 + 20 `#[ignore]`，其中安全审计那轮新增 **7** 条）· 前端 **167** 项 · `tsc --noEmit` 0 错 · 文档链接 0 断链。
- **打包验证**（2026-10-30 **23:13 重打后**的实测，不是"应该没问题"）：
  - 本次构建窗口内 `target/release/build/app-*/output` **无** `cargo:rustc-cfg=dev` → 是打包版，不会去连 `localhost:5173`；
  - `msiexec /a` 解包 MSI → 只有 `app.exe`（25,395,200）+ `app_lib.dll`（1,736,704）；
  - 便携版 exe 拷到**空目录**双击：窗口标题「织梦机」、进程健在（FileVersion **3.11.0**）；
- 顺带改掉两处**过期文案**（不是功能）：插件页「🌱 三维数值自动变化」的面板还写着已删除的「没睡好 −5」、关键记忆页还写「承诺每种只记第一次」；
  现在面板只列真实存在的类型，记忆卡改成「表白 / 牺牲 / 背叛每种只记第一次，**承诺允许多条**」。
- 数据库新增三张表这事，[数据与备份](https://github.com/gu-chen-xi/story-weaver/blob/v3.11.0/docs/user/数据与备份.md) 已同步。
