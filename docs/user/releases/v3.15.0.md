## 一、立绘不再走"整块磁盘"（安全）

**原来的问题**：`tauri.conf.json` 里

```json
"assetProtocol": { "enable": true, "scope": ["**"] }
```

`**` 就是"任何路径"。这不是理论风险：**只要 webview 里有一段不受控的脚本**，它就能把本机任意图片读出来画到页面上。

**现在怎么做**：新增自定义协议 `portrait://localhost/<文件名>`（`src-tauri/src/portrait_protocol.rs`），三条边界：

| 边界 | 判据 |
|---|---|
| 只认**文件名** | URI 里出现 `/`、`\`、`..`、`:` 一律 **403**；而且是 **percent-decode 之后**才检查 —— 顺序反了的话 `%2F` 能绕过 |
| 落点固定 | 永远拼在 `portraits_dir()` 里，出不去 |
| 读不到就 404 | 不回落、不猜、不列目录 |

配套改了三处：

- **CSP**：`img-src` / `media-src` 里的 `asset: http://asset.localhost` → **`portrait: http://portrait.localhost`**；
- **`assetProtocol` 整块删掉**，`Cargo.toml` 里的 `protocol-asset` feature 也删了；
- **加结构守卫**（`security_guards.rs`）：配置里再出现 `assetProtocol`、CSP 里再出现 `asset:`、
  `lib.rs` 里丢掉协议注册 —— 任何一条都让测试变红。**关掉的风险不会自己走回来。**

前端只改了拼地址的地方：`lib/portraitSrc.ts` 一个函数，取文件名 + `encodeURIComponent`
（Windows/Android 上 WebView2 把自定义协议暴露成 `http://portrait.localhost/…`，其它平台是 `portrait://localhost/…`）。

> **备份不受影响**：立绘文件还在 `library/default/shared/portraits/`，一个字节没挪，只是**读的方式**变了。

## 二、命令面：登记表、插件白名单、四条原生确认（安全）

背景是 3.11 那轮安全审计留下的 F-05：**160 条命令对主窗口全量开放** —— 前端只要有一次脚本执行，
就能调"删故事 / 回滚快照 / 清调试记录"的全部能力。Tauri 没有"按命令"的 ACL（`capabilities` 只管插件权限），
框架层收不窄，所以这一版把**能做的三件事**都做了：

### 2.1 命令登记表（160 条逐条登记）

新模块 `command_registry.rs` 把每条已注册命令登记一行，并标上能力域：

| 域 | 含义 | 例 |
|---|---|---|
| `Read` | 只读 | `list_stories` / `scan_foreshadow_cloud` |
| `Write` | 写 | `create_story` / `apply_check_patch` |
| `Sensitive` | **会丢数据** | `delete_story` / `rollback_snapshot` / `purge_temporary_snapshots` / `undo_relation_change` |
| `Credential` | 凭据 | `keychain::set_api_key` |
| `Dev` | 开发者工具 | `dev::dev_rollback` |

测试有三条硬要求：① 登记表与 `generate_handler![]` **逐条一致**（漏登记 / 多登记都红）；
② `delete_/remove_/purge_/clear_/rollback_/undo_` 开头的命令**必须**标 `Sensitive`；
③ 凭据类必须标 `Credential`。它不限制调用，但**"悄悄多出一条命令"这件事从此不可能发生**。

### 2.2 四条不可逆命令改弹**系统**对话框

`delete_story` / `rollback_snapshot` / `purge_temporary_snapshots` / `delete_branch` ——
这四个丢了就真没了。原来只有网页里的确认框，而**网页确认框挡不住注入的脚本**（它能自己再调一遍 `confirm`），
所以改成 `tauri-plugin-dialog` 的**原生**对话框（`confirm_destructive`）。

其它写操作不加确认：有版本快照兜底，每次都问反而会让人闭眼点「确定」。

### 2.3 插件只能调白名单里的命令

插件是**跑在同一个 webview 里的 JS**。以前直接把 `invoke` 交给插件，它就能调后端任何一条命令。
现在宿主机只交一个 `host.call(name, args)`，`name` 必须落在白名单里：

| 白名单（13 条） | 给谁用 |
|---|---|
| `ollama_get` / `ollama_set` / `ollama_probe` / `ollama_test_chat` | Ollama 本地模型插件 |
| `generator_list` / `_probe` / `_generate` / `_cleanup_temp` / `_list_temp` / `_ingest` / `_get_cloud_config` / `_save_cloud_config` / `_clear_cloud_key` | 立绘生成插件（含云端通道） |

表外直接抛错，错误信息里**列出可用命令**（不然插件作者只能猜）。另加一条守卫：插件目录里出现
`@tauri-apps/api/core` 就红 —— 想"绕过白名单自己 import invoke"这条路也堵上。

> 完整的命令面风险（还剩什么没关）写在 [SECURITY.md §3.8](https://github.com/gu-chen-xi/story-weaver/blob/v3.15.0/SECURITY.md)。

## 三、日结顺手把新人物记下来

剧情里第一次出现「阿婆」时，以前的处理是：**你发现**、你去角色页新建、你填一句话说明。
现在日结那一次请求顺带抽出来，进「待确认」。

### 3.1 为什么挂在日结

日结本来就要读当天全文，而且**每天只跑一次**。放进主对话就是每轮多一句提示词 + 多一次判断，
而"今天有没有新人物"一天最多变一次 —— 和「她的告白」是同一个理由。

### 3.2 六种协议行

模型在摘要之后再写几行（冒号全角半角都认）：

```
〔新角色〕阿婆：住在隔壁的老人，总在傍晚坐在门槛上
〔新地点〕西厢房：院子西边那间，锁着
〔新术语〕三更鼓：镇上夜里报时的鼓
〔世界观〕河神娶亲：每年七月十五要往河里放一盏灯
〔改角色〕阿婆：其实是他亲奶奶
〔改设定〕西厢房：后来改成了书房
```

- **只写第一次出现的**；已有的不重复写；冒号后面不写剧情过程；
- 每种最多 2 条、**一天最多 6 条**（防报菜名，也防一次塞爆审批队列）；
- 这些行**从摘要正文里剥掉**，不会跑进【前情提要】。

### 3.3 必须先把"已经有什么"告诉它

这是这一版最实在的一条教训：**只写"只输出新的"是不够的** —— 模型手里只有当天正文，
它不知道谁算"旧的"，于是 deepseek-flash **一条都不写**（实测，换成"必须"也一样）。

所以日结的输入末尾固定拼两行：

```
【已有角色】顾宸熙、夏婉琴、老张头…
【已有设定】老宅、镇公所、三更鼓…
（只写**不在这两份清单里**的新东西）
```

加完当天就能抽出「阿婆」这类新称呼。这条也补了提示词守卫：以后谁把清单删了，测试会红。

### 3.4 去重、置信度、以及"改已有条目"

| 项 | 口径 |
|---|---|
| 去重（三路） | ① 库里已有同名角色 / 同 key 设定（**只跟当前分支比**）；② 已在队列里的同名 pending / rejected 提案（**拒绝过的不会天天重提**）；③ **名字变体**：「王阿婆」=「阿婆」（尾缀相同、长度差 ≤2），但「阿婆的儿子」**不算** —— 只认尾缀，因为中文称呼的修饰语都在前面 |
| 置信度 | 按**这个名字当天被提了几次**给分：`0.55 + 0.1 × min(次数,3)`（0.55~0.85）。模型给不出概率，就用能数的证据 |
| 改已有条目 | 只改**一句话设定**（角色的一句话 / 设定的值）；名字必须**唯一命中**（没找到 = 这是新东西，撞上多个 = 不猜）；内容没变不提案；同一目标同一新值不重复排队 |
| 落地 | 新增 = 插入角色 / 世界书条目；改 = 核旧值后更新。**两者都打快照 + 写审计**，和关系提案同一套 |

### 3.5 提案页现在看得懂了

以前新增类提案在列表里只显示一个载荷字符串。现在：

- 标题：`👤 新增角色：阿婆` / `📍 新增地点：西厢房` / `📖 新增术语：三更鼓` / `🌍 新增世界观条目：…`；
- 正文：`阿婆 — 住在隔壁的老人，总在傍晚坐在门槛上`；
- 按钮：「确认新增」/「忽略」（关系类仍是「落地 / 拒绝」）；
- 顶部多一排 **「只看：全部 / 关系 / 角色 / 设定」** —— 提案一多，混着看不动。

日结抽到东西时，左侧「待确认」红点会**立刻亮**（以前要等你手动刷新），提示条里也会写抽到了谁。
顺便：**日结被跳过时也会说一句**「日结跳过：这一天没有剧情」—— 以前点了像没反应。

## 四、伏笔：云端那一档接上了

3.12 只做了本地模型扫描。3.14 把协议拆成"双规制"（本地单步、云端两步），但**云端那一档一直没接**。
这一版接上了：

- 「历史章节」伏笔区多一个 **「☁ 云端扫描伏笔」**；
- 走**主模型**（`call_summary_model`，自带关思考 / 空正文诊断 / 重试一次）；
- 用**两步式提示词**：第一步一条一行列细节并标 `→ 是` / `→ 否`（"这条当场被消化了吗"），
  第二步只把「否」改写成 `〔伏笔〕…`；
- 与本地扫描**共用**分批 / 前情窗口 / 解析 / 模糊去重 / 进度事件，差别只有"调谁 + 哪份提示词"；
- 结果 `source=cloud`，和本地 / 规则扫描进同一个提议列表，谁扫的都一样要你点头。

**代价要说清**：每章一次请求，**会花 token**（按钮的悬停提示里写明了）。
本地那档要 **~27B 才勉强稳定**（7B/9B 会明显漏判，甚至给出错的结论），显存不够就别硬开本地。

顺手修掉一个老账：本地扫描里"已发现的候选带进后续批次"那段**从来没生效过**
（`found_now` 声明了却从未写入）—— 现在抽成纯函数 `accumulate_prev_found`（去重 + 最近 10 条），有两条测试锁着。

## 五、图床白名单，与"坏图不许把进程吃死"

### 5.1 跨源图床白名单

安全审计 F-01 当年的取舍是：跨源图片**一律不带凭证**，于是"图床在别的域名又要求鉴权"的服务必然 401。
正确解法不是放开凭证，而是让你**点名**信得过的域名：

- 新配置键 `portrait.cloud_download_hosts`（逗号 / 分号 / 空白分隔，支持 `*.example.com`）；
- **只有命中白名单的跨源域名**才带鉴权头；
- **白名单不解除本机 / 内网禁令** —— 就算你把 `127.0.0.1` 写进去也照样拒绝（防 SSRF 的底线）；
- 匹配容忍大小写、末尾点号、条目里的端口；`*.b.com` **不**命中 `b.com` 本身；
- 界面上在「插件 → 立绘生成 → 云端通道」里多了一个输入框，**留空 = 老行为**。

### 5.2 解码前先设上限

安全审计里挂着的最后一条（"恶意图片字节喂解码器"）也在这一版验完了。它背后是个真坑：
一个**三十字节**的 PNG 只要在 IHDR 里写 `100000×100000`，解码器照着声明分配内存就是几个 TB。

现在解码前设 `image::Limits`（宽 / 高各 **16384**，远超任何正常立绘），超限直接报「解码失败」。
测试四条：空 / 垃圾 / 截断字节必须报错、伪造超大尺寸必须被拒、上限值本身合理、
`image_size()` 对坏文件和不存在文件返回 `(0,0)` 不 panic。

## 六、输入台：底栏收进一个「＋」

以前底栏一排小控件（敏感词 / 约束 / 时段 / 导演指令 / 账本 / 长度 / 记忆 / 回顾）。这一版收进一个圆形 **「＋」**：

- **平时只剩 ＋、Token 圆环、字数、圆形提交键**。点 ＋ 弹出抽屉，展开时 ＋ 转成 **×**；
- 抽屉走 **Portal** 挂到 `body` 上 —— 放在流里会把输入框撑大（实测图）；位置按底栏与按钮的**实测坐标**算，
  贴在 ＋ 正上方、宽度跟输入卡片一致、`maxHeight: 58vh` 可滚；
- **竖排**，顺序按你定的来：长度 → 时段 → 回顾 → 导演指令 → 账本 → 约束 → 记忆 → 敏感词；
- 点抽屉外面自动收起（点输入框不算外面，那是继续打字）。

顺带改了四样：

| 改动 | 为什么 |
|---|---|
| 旁白 / 对话 **合成一个按钮**（点一下切换，带 `⇄`） | 两个按钮 + 一行说明占了一整行；说明挪进 `title` |
| Token 指示 **圆点 + 46px 长条 → 一个 12px 圆环** | 同样的信息，四分之一的位置；文字只留百分比，悬停看「已用 / 上限」 |
| 提交 / 停止 **改成圆形** 34px | 和 ＋ 一个视觉体系；生成中显示 `■`、平时显示 `➤` |
| 输入区**外层去掉底色与上分隔线**，与对话区之间留 8px | 最后一行消息不再贴着输入框 |

## 七、观感三件

1. **滚动条平时隐形**：滚动 / 拖动时出现，**停手 3 秒淡出**（对话区与导演监视器同一套）。
   实现上踩了两个坑，都记进错误合集了（E-UI-27）：一旦设了 `scrollbar-color`，Chromium 就忽略 `::-webkit-scrollbar` 那套定制；
   而"条件渲染的元素"挂载那一帧 `ref` 还是 null，监听会永远挂不上。
2. **危险按钮按下去有手感**：下沉 1px + 内阴影 + 变暗（`.btn-press`）。目前 **28 个**按钮带它 ——
   删除 / 回滚 / 清理 / 刷新一类；普通按钮不凑热闹。
3. **全站数字等宽**（`tabular-nums`）：百分比、字数、倒计时不再左右跳。
