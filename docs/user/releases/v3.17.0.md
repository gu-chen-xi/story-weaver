## 一、首页：打开就能接着写

以前 `home` 视图**没有渲染分支**，打开软件只有一句「从左侧导航选择功能」的空白页。

- **启动台**：按本地时段问候（夜深了 / 早上好 / 中午好 / 下午好 / 晚上好），副标题带最近故事名；
  「继续创作 · {最近更新的故事}」直接进剧情区；「＋ 新建故事」；「最近编辑」前 3 条
  （首字方块 + 时间起点 + 相对时间 + 📜 有前史，hover 出「进入 →」）；「全部故事 →」。
- **数据只用故事列表**：不为了首页去开每个故事的 `story.db` 数节点；空态是虚线框「还没有故事」。
- **「最近编辑」排序 = 最近写过**：`stories.updated_at` 以前只在建故事时写一次（首页其实是"最近创建"）；
  现在**写/改一条消息**时才更新（进入故事不算）。错误合集 [E-UI-30](https://github.com/gu-chen-xi/story-weaver/blob/v3.17.0/docs/dev/错误合集.md)。
- **进故事不再闪一下时间线**：`enterStory` 改成"数据备齐再切页"，加载期间停在首页显示「进入中…」，
  节点/分支越多越明显（原来白渲染一遍最贵的时间线树）。错误合集 [E-UI-31](https://github.com/gu-chen-xi/story-weaver/blob/v3.17.0/docs/dev/错误合集.md)。
- 左上角 Logo 点击回首页；点导航「演进提案」会顺手刷新一次（重复点也刷）。

## 二、大肥鱼图标集 v1

## 三、提示词：认知边界 + 预览与真实同源

- **【已知与未知】**：角色视角下补一段"你只知道这些"——有名有姓的人、已确立的事、具体数字，
  **不知道就说不知道**；环境与无名细节可以随口带过（不然角色会变木头）。
- **尾部装配去重（ROADMAP §2.1 #23 关闭）**：关系强度 / 角色属性 / 示例对话原来**另抄一份**选择逻辑，
  抄错就是"预览骗人"。现在 `tail_view.rs` 是唯一实现，`TailCtx` 强制带
  `{branch, scope, ai_role, focus_role, panel_focus}`（少传一个编译不过）；真实装配与预览都调它。
  之前记的 3 处差异（属性块先看 `@焦点`、示例对话三级回落、台词取人）随之消失。
- **双池对比更好用**：两边一样的尾部块（关系强度 / 示例对话）以前被"通用段"吞掉不显示，现在单列；
  护栏通过出**绿条**、数据在请求之后变过出**黄条**（不再一律红）、连名字都对不上才红条；
  预览复现**最近一次请求的 `@焦点`**，界面会标注。
  错误合集 [E-UI-32](https://github.com/gu-chen-xi/story-weaver/blob/v3.17.0/docs/dev/错误合集.md) /
  [E-UI-33](https://github.com/gu-chen-xi/story-weaver/blob/v3.17.0/docs/dev/错误合集.md) /
  [E-AI-39](https://github.com/gu-chen-xi/story-weaver/blob/v3.17.0/docs/dev/错误合集.md)。

## 四、记忆卡与日摘要

- 记忆卡正文按**角色名**渲染（不再出现 `[用户]` / `[AI]`），并带 `ai_side` 方向；
  老卡读时兜底；表白卡写清「顾宸熙第 1 次向夏婉琴表白」，日结侧有闸门（不把 AI 的表白记成用户的）。
- 记忆卡搬进**角色详情卡弹窗**（按关系组分组），时间线页底部那个总面板删掉、树状图撑满高度。
- 正文的 `**加粗**` 与 `*斜体*` 都渲染（未成对的标记原样显示）。
- 修 `strip_confessions` 的字面 `\n`（错误合集 [E-AI-38](https://github.com/gu-chen-xi/story-weaver/blob/v3.17.0/docs/dev/错误合集.md)）。

## 五、摘要管理的三个口径

- **覆盖天数按区间并集**：5 条「第 1~13 天」的重复段以前会被算成「已压缩 65 天」，现在 13 天。
- **未压缩 = 本分支现有天 − 覆盖**（不管有没有日摘要）：主线 17 天、压了 13 天，就是「未压缩 4 天」；
  另外单列「可压 N 天」（未覆盖且有日摘要，真正能压的），并说明"这 4 天还没日摘要"。
- **「N/M 天有摘要」用本分支数字**：以前 M 是**整棵树**的天数（所有分支之和）。
- 顺带：面板底部「清理重叠」只动当前分支、每段保留最新。错误合集
  [E-DB-22](https://github.com/gu-chen-xi/story-weaver/blob/v3.17.0/docs/dev/错误合集.md) /
  [E-DB-23](https://github.com/gu-chen-xi/story-weaver/blob/v3.17.0/docs/dev/错误合集.md)。
