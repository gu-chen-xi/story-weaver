# 织梦机 · Story-Weaver v3.2.0

> 这一版**只做一件事**：让模型真正看到角色的四维状态。

---

## 新增：角色四维属性进提示词

**之前的问题**：`体力 / 理智 / 情绪 / 存在感` 这四个属性一直只存在数据库里、显示在导演监视器上 ——
**模型完全看不到**。所以界面上明明写着"理智 20"，生成出来的角色却依然神志清醒、条理清晰。

**现在的做法**：注入尾部【数值与状态】块，按「档位(数字)」双写：

```
【数值与状态】（本节的数值为当前真值，以本节为准；历史中的旧数值/旧状态作废）
角色属性（只作状态与倾向的参考，靠动作/语气间接表现，不要报数字）：
- 夏婉琴：体力 偏低(30) · 理智 正常(55) · 情绪 很高(90) · 存在感 偏低(25)
关系强度与状态：
- A → B：强度 83（羁绊）…
```

为什么不是裸给数字：直接塞 `体力 30` 会让模型演成游戏血条（"我只剩 30% 体力了！"），破坏叙事语感。
档位给**表演方向**、括号数字给**精确值**，主次明确。

同时【数据字典】新增四维解释（此前只有关系强度/状态），并把一条硬约束写死：
> 表现方式：靠动作、语气、身体反应间接体现（如「手在抖」「没接话」「难得提高音量」），不直接报数字。

**预算控制**：焦点角色优先注入；自由模式最多列 8 个角色（每个约 25 token），超出提示"（其余 N 个角色略）"。
