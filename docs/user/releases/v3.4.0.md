# 织梦机 · Story-Weaver v3.4.0

> 这一版是三件事：**角色能记事了**（角色卡 v2）、**世界观能记东西了**（物品库）、**故事有了前史**。

---

## 新增：角色卡 v2 —— 过去 / 动机 / 目的 / 行为准则 / 对话示例

**之前的问题**：角色只有"小传 + 性格标签 + 说话方式"三样，写多了会糊成一团；
写少了模型只能自由发挥 —— 于是同一个角色在不同章节里像两个人。

**现在**：每个角色多了五个作者字段。

| 字段 | 作用 | 进哪 |
|---|---|---|
| 过去 | 他的往事（那场火、那个雨夜）| system 角色段，截断 400 字 |
| 动机 | 他为什么这么做 | 同上 |
| 目的 | 他想达成什么 | 同上 |
| 行为准则 | 他会怎么做 / **绝不**做什么 | 同上 |
| 对话示例 | few-shot：他说话的样子 | **尾部块**，只给一个角色，截断 800 字 |

**为什么"对话示例"单独走尾部块**：
它体积最大、且随"当前角色卡"变化 —— 塞进 system 会推高固定区、还会破坏前缀缓存。
尾部块本来就不吃缓存，放这里最合适。

示例对话的归属怎么定（四级回落）：
1. 你输入里 `@角色名` 提到的那个
2. 否则 AI 扮演的角色
3. 否则导演监视器里「当前角色卡」的那个
4. 都不满足 → **不给**（宁缺勿滥，不乱套别人的说话方式）

提示词里还写死一句约束：
> 只用于**模仿语气、用词、停顿与反应方式**，不要照抄内容、也不要直接接续它。

否则模型会把示例当剧情续写 —— 这个坑实测踩过。

**AI 改不了这五个字段**：一键替换的白名单故意不收录。
角色的过去和动机是作者的设定，不该被 AI 的"一致性修正"顺手改掉。

## 新增：🎒 物品库

世界观设定页多了「物品库」页签，放"出现的勤的东西"——怀表、钥匙、显卡、药瓶。

- 字段与术语同构：**物品名 / 别名 / 说明**
- **全量进提示词**：`- 物品「怀表」：B 送的，走时慢三分钟（别名：旧表）`
- **参与回顾召回**：物品名和地点/术语/势力同等权重，提到它时更容易带回相关那天
- 带搜索框（几十上百条也不难找）

## 新增：前史 / 序章

故事开始之前发生过什么（"三年前 A 与 B 在码头分开"）——**故事级**数据，不随分支变化。

非空时在提示词的 `【前史】` 段出现，位置在 `【世界观】` **之前**，并声明：
> 属于已确立的背景，**不是本轮剧情**；与后文设定冲突时**以前史为准**。

空串整段不出现 —— 老故事升级后提示词零变化。

## 修复

- **回顾认不出别名**：召回词典原来只取条目**名称**，
  所以「rtx显卡（别名：显卡）」这种条目，你输入"显卡"永远匹配不上。
  现在名称与别名一起进词典（中英文逗号/顿号/分号都认，单字别名丢弃）。
- **只命中一个专有名词也带不出来**：`entity` 权重 12 低于 `min_score` 20，
  等于"看得见但带不出"。已提到 20（与日常标签词同档）。
- **示例对话从不注入**：焦点角色来自输入里的 `@角色名`，不 @ 就没有焦点 →
  原来直接跳过。现在按上面那四级回落选人。

## 数据兼容

老库启动时自动补列（`prologue`、角色五个字段），不需要手动迁移；
空值一律按"没写"处理，老故事的行为不变。
