# 织梦机 · Story-Weaver v3.5.0

> 这一版是四件事：**世界观能按需进提示词了**（世界书）、**角色真的会拒绝了**（关系配合度 + 情绪改造）、
> **不会忘记重要的事**（关键记忆）、**角色能有长相了**（外貌）。
>
> 另有一批"看不见但影响手感"的调整：提示词结构重排、日摘要省 token、数据字典英文化。

---

## 新增：📖 世界书 —— 按需注入的世界观条目

**之前的问题**：上一条世界观设定会**每轮都进提示词**。写得越多，system 越胖，
而且大部分内容和当前场景无关 —— 白烧 token，还挤掉了真正相关的设定。

**现在**：世界观设定里多了一类「世界书」。它不常驻，**命中触发词才进**。

| 你填的 | 作用 |
|---|---|
| 触发词 | 用户输入或最近 3 条消息里出现这些词，这条才注入（逗号分隔，支持别名）|
| 常驻 | 勾上 = 每轮都进（和旧行为一样）|
| 优先级 | 多条同时命中时谁先进（0-100）|

**注入位置**：尾部块（易变区）的 `【世界书】`，每条都带命中标注：

```
【世界书】
- 「怀表的来历」（命中：怀表）：B 母亲留下的，走时慢三分钟
- 「城北的规矩」（常驻）：入夜后不开北门。
```

**预算**：1200 字，按优先级排，超出的会注明"另有 N 条未注入"。

> 为什么放尾部块：世界书是"随场景变化"的内容，塞进 system 会破坏前缀缓存。
> 尾部块本来就不吃缓存，放这里最合适。

## 新增：关系配合度 —— 角色会拒绝、会拖、会谈条件

**之前的问题**：关系强度只是个数字标签（"83 羁绊"），模型并不知道它意味着什么；
于是低强度的角色照样有求必应 ——"该拒没拒"。

**现在**：【配合度】段把强度**翻译成合作意愿**，并且写死三条边界：

- **低强度默认拒绝**：可以拒绝、回避、拖延、谈条件；亲密接触一律先拒；
  主动配合必须有明确理由（对方先让步、有交换、或剧情需要）
- **硬触发清单**：上一轮有肢体伤害且未道歉 / 强度 < 20 且对方提亲密接触 /
  台词与身体冲突 → **必须明确拒绝**，不许口头敷衍就放行
- **拒绝之后就停住**：不加缓和句、不加"但是"、不加半推半就的动作（让开半步、手松开、补软话）

同时补上**关系态势**（稳定 / 紧张 / 破裂）的行为规则 —— 之前它只是个标签：

| 态势 | 意味着 |
|---|---|
| 稳定 | 可以拌嘴、冷脸，但不动手、不翻旧账、不断联；一句话能回缓 |
| 紧张 | 会翻旧账、说重话、试探底线；事后需要**一件具体的事**才能缓和 |
| 破裂 | 回避、断绝、伤害性言行；配合度整体下调一档，**不接受无代价的和解** |

两者分工：**强度管"愿不愿意"，态势管"闹到什么程度"**。
冲突时以态势定烈度、以强度定语气温度 —— 羁绊 + 破裂 = 越痛越狠，话说得越软越伤人。

## 改：角色的「情绪」不再是数值，改由「当下」描述

**之前的问题**：情绪是个 0-100 的数字（"情绪 很高(90)"）。可"很高"到底是暴怒还是喜极而泣？
数字答不了 —— 它和真正要演的戏没关系。

**现在**：情绪数值**去掉了**（角色属性从四维变成三维：体力 / 理智 / **存在感**），
改由角色卡上的「当前状态」文字表达，并进提示词：

```
- 夏婉琴：体力 偏低(30) · 理智 正常(55) · 存在感 偏低(25)｜当下「刚被拒绝，强撑着」
```

表演按这个走：**崩溃 → 哭泣、决绝、歇斯底里；强撑 → 话少、动作僵硬、突然沉默**。
不再一律甜腻，也不再一律拒绝。

新增的【情绪表演】段给了三者分工（这也是这一版最有用的一条）：

> **情绪只定方向；强度定藏露；理智定语量。三者冲突时以强度优先** ——
> 疏离档下，任何情绪都不外放给对象看。

同一个"崩溃"的四种写法：

| | 理智低 | 理智高 |
|---|---|---|
| **强度低** | 转身、挡脸、话断在半截，不哭给你看 | 答非所问、语气平得反常，事后才失态 |
| **强度高** | 当场散架，说不完整的话，抓住人不放 | 一句一句说完，说得很清楚，越清楚越吓人 |

## 改：心声不再一律"口是心非"

**之前的问题**：提示词要求"心声必须写出与台词相反的想法"。
结果所有角色都被写成傲娇腔，而且这种"嘴上冷心里热"还会**反向助攻** ——
明明该拒绝，心声先软了。

**现在**：心声与台词的关系**有六种**，按人物此刻状态自然选：

| 类型 | 例 |
|---|---|
| 反向（口是心非）| *有事。但我不会说给他听。* |
| 旁支（跑题）| *他袖口上沾了灰。* |
| 自欺（找台阶）| *我只是懒得争，不是在意。* |
| 掐断（说到一半停）| *我本来想说——算了。* |
| 钝（只有身体感）| *耳朵在响。* |
| 算计（盘算利害）| *现在翻脸，吃亏的是我。* |

保留两条边界：疏离/戒备/拒绝越界时，心声必须**与台词同向**；
心声不许写成对剧情的总结或对人物的点评。

## 新增：🧠 关键记忆 —— 只记第一次

**之前的问题**：日摘要记的是"那天大概发生了什么"。但有些事是**不可重来**的 ——
表白、承诺、牺牲、背叛。模型不知道"她已经表过白了"，就会一遍遍重演第一次心动。

**现在**：系统从剧情里自动提炼这四类事件，**每种只记第一次**，一个事件一份 Markdown 文档：

```
<数据目录>/library/default/projects/<故事>/memories/001-表白.md
```

注入到尾部块：

```
【关键记忆】本故事里已经发生、不可重来的事（不要重演第一次；可作为回忆、心结或情绪的来处）
- 第 4 天 · 表白：……
```

**没有"新建"入口**（它是从剧情里提炼出来的，不是手写的设定），但你可以**改正文、删掉误记的条目**。
时间线页底部有「🧠 关键记忆」面板。

**导出**：和"故事导出"同一个保存位置，但用文件夹包着，名字叫 `key-memories`：

```
key-memories/故事名_20261023_1345/
  001-表白.md
  002-承诺.md
  INDEX.md
```

## 新增：角色卡「外貌」

角色表单多了一项**外貌**（和过去/动机/目的/行为准则同级）。
进 system 角色段，截断 300 字。**AI 改不了**（一键替换的白名单不含它 —— 外貌是作者设定）。

「身份」没有新增字段，继续用现有的**一句话身份**。

## 改：日摘要改成"每满 10 条刷新一次"

**之前**：当天回复超过 10 条之后，**每加一条都会重新生成一次日摘要** —— 费 token，
而且每轮都把当日摘要改掉，前缀缓存也跟着散。

**现在**：每满 10 条（10 / 20 / 30 …）刷新一次。同一个轮数重复调用不会重跑。

## 改：提示词结构（看不见，但影响手感）

- **数据字典英文化**：关系强度/态势/角色属性的说明改成英文脚手架（**中文枚举值保留**），
  因为英文指令更容易被模型准确读成规则。末尾显式写死"输出必须是简体中文"。
- **术语定死**，消灭"状态"一词三义：
  关系层面的 `稳定/紧张/破裂` 叫**关系态势**；
  角色此刻那一行叫**当下**；
  `情绪` 不再是字段，而是"从当下 + 强度 + 理智读出来的方向"。
- 尾部块标题 `【数值与状态】` → `【数值与当下】`。
