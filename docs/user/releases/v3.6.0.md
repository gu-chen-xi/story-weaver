# v3.6.0 — 时间线看得见了，插件装得下了

> 发布 **2026-10-24** · 上一版 [v3.5.0](v3.5.0.md)
>
> 这一版做了两件事：**把时间线做成能看的图**，**把插件系统从"散装"收成一个体系**。
> 顺手删掉了一批重复入口 —— 这一版净减代码，但功能是变多的。

---

## 一、时间线：段框树 + 逐日模式

原来的"树状图"是一行行缩进列表，分叉多了根本看不出来。现在有两种视图：

**段框树**（默认）—— 一条线一个框：

```
┌─ 主线 ─────────────────┐
│ 第 1 天—第 6 天 · 6 个节点 │
│ ●●●●●★                  │
│ ★ 第 6 天 = 分叉点       │
└──────────┬─────────────┘
     ┌─────┴──────┐
  ┌──主线──┐  ┌─从6分支─┐
  │第 7 天 │  │第7—10天│
  └────────┘  └────────┘
```

* 框与框之间**曲线连边**（SVG，画在框下面，不挡点击）；
* 分叉点标 `★`，当前所在标 `●`，插曲/倒叙标 `◇`；
* 还没开始的线显示成**虚线框**（不隐藏，否则你不知道它存在）；
* 天数"倒挂"（第 20 天接第 9 天）也照样按父链排，不会被打乱。

**逐日模式** —— 一天一颗药丸，分叉用大圆点岔开，线名标在起点下面。

两种模式都是**渲染前算好布局**（不用 DOM 测量），所以流式生成时不会跟着抖。

## 二、对话区：一个不动的头 + 一条能滑的天

**上面的框固定不动**，两排：

1. 分支切换条 + `+ 下一天` / `⏳ 插入事件` / `🎭 插入插曲`
2. **这条线的所有天**（药丸，左右滑动）

进入对话区或切换分支时，会自动滚到**最后一天**；同一条线内点别的天不会乱滚
（不然你正想看的几颗就被弹走了）。

它**真的不动**：这块内容渲染在滚动容器**外面**，不是 `sticky` ——
`sticky` 只是"贴顶"，滚动时仍会跟着走。

> 「⏳ 插入事件」是这一版补回的入口：它能在**没有剧情的空白期**里插一天
> （比如第 3、4 天没写，就补在中间）。选哪段空档由当前天决定，往后找，不往回跳。

**提示条**也搬家了：所有提示（"已切换到…""正在生成中…"出错）现在固定在
**标题栏下面那一条**，不再挤占内容、也不会把上面的头挤下去。

## 三、表演标签：动作与情绪

回复里的括号表演段会被识别成**动作**与**情绪**，共 100 多个词、各分 6 组
（靠近/退开/定格/手部/视线/声音；暖/冷/紧/散/炸/弱），右下角导演监视器直接显示。
后台也会静默记一条（不打扰你写作）。

## 四、插件系统：一个注册表，一条命令

以前"加一个插件"要同时改四个地方（注册表、页面里的 if、卡片、hook）。
现在只有两步：**建一个目录 + 注册表加一行**。

```
src/plugins/
  types.ts        契约（元信息 / 能力声明 / 徽标 / 手动运行）
  PluginCard.tsx  通用卡片 —— 只排版，不认识任何插件 id
  registry.tsx    注册表 ← 加插件只改这里
  builtin/
    evaluate/         评估模型（带徽标 + 手动运行）
    portrait-gen/     立绘生成（带大面板 + 云端表单）
  _template/        可抄的示例模板（永远可编译，不会过期）
```

配套：

* **开发文档**：[`docs/dev/PLUGINS.md`](../../dev/PLUGINS.md)（三步加插件 / 宿主给你什么 / 配置键 /
  安全边界 / 测试要求 / 常见问题）；
* **示例模板**：`src/plugins/_template/`（3 个文件：`manifest` / `panel` / `index`，字段都带注释）；
* **守卫**：页面里再出现 `if (id === "evaluate")` 这种分支，`cargo test` 直接红。

> 目前实装的插件：**评估模型**、**立绘生成**（云端/本地双通道）。
> Ollama 本地模型是规划中的插件位，还没做。

## 五、这一版删掉的东西

减法同样是功能。删的都是**重复入口**或**没人走的路径**：

| 删了什么 | 为什么 |
|---|---|
| 时间线的「列表」视图 | 和树状图表达同一批节点 |
| 列表/日历下面的「天数排」 | 换成对话区上方那条（更贴近写作时看） |
| 「攒够 N 天 / 压一段摘要」控件 | 导演监视器里已经有一份，两处都能压会让人不知道信哪个 |
| 故事页头的「流式输出」「已自动保存」徽章 | 常驻但几乎不提供信息 |
| 角色详情卡 / 立绘素材页 / 角色卡 / 参数页的 4 处「AI 生成立绘」入口 | 统一走「插件」页 |
| `lib/timelineTree.ts` + 它的 8 个测试 | 段框树改用新的分段模块后成了死代码 |

## 六、修掉的问题

* **删掉中间一天，后面整段消失**：删节点时没把它的子节点接回去，`parent_id` 指向已删除的行，
  整条后半段从根不可达。现在删除时自动重接到祖父，**启动时还会自愈历史数据**。
* **时间线只剩主线 / 画出假分叉**：断链节点被整棵丢掉，或被当成"分支"挂到根。现在按线接回。
* **从分支新建「下一天」跑到别的分支**：点节点时静默忽略了你的点击；空分支落在别人的节点上；
  嵌套子分支的分叉点属于父分支，被后端按节点推导抢走。三处都修了，**界面现在优先**。
* **只有一条孩子链的分叉认不出来**：判据加了 `branches.fork_node_id`，嵌套分支不再被父段吞掉。
* **角色卡里「动作」重复显示**、**关键记忆面板把 Markdown 当纯文本**（标题重复、露出符号）。

## 七、内部（用户看不到的）

* `App.tsx` **1412 → 1248 行**（状态按页面收进 5 个 hook；成片 props 收成带类型的对象），
  结构守卫上限从 1650 下调到 **1300**；
