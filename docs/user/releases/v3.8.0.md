# v3.8.0 — 她拒绝的时候，软件不再"猜"了

> 发布 **2026-10-26** · 上一版 [v3.7.0](v3.7.0.md)
>
> 这一版的主题是「**把判断交给协议，别交给措辞**」：关键记忆不再猜 AI 说了什么，
> 而是让它在最后一行直接写「接受 / 拒绝」；顺手修掉一批「界面和数据各说各话」的问题。

---

## 一、关键记忆：从"猜措辞"改成"读标记"

**之前的问题**：软件要判断「这次表白是被接受还是被拒绝」，靠的是关键词表。
但真实的拒绝长这样：

```
「别说了。」「这种话，我不接。」
「说多了，就不算数了。」
「你认错人了。」「这种话，别在我这儿放。」
「你这算什么。」「刚还念数字呢。」
```

词表补了三轮，每轮都被下一句打脸 —— 这条路没有尽头。更糟的是：判定成「未判定」的记忆，
提示词会告诉模型「这件事发生过、对方态度不明」，于是它越演越软（"软接受"）。

**现在的做法（协议，不是猜测）**：这一轮你的输入涉及**表白或承诺**时，
软件在提示词末尾加一句：

> 请在回复的**最后一行**，从下面两行里原样输出一行：
> 接受时输出：`〔态度:接受〕`
> 拒绝或回避时输出：`〔态度:拒绝〕`
> 这一行只给软件记录用，不会被展示出来，也不影响你正文怎么写。

判定优先级：**标记 > 台词打分 > 未定**。模型偶尔忘写（长回复、被截断），就自动回落到打分器 ——
所以你会看到「偶尔判成未定」，那是兜底在工作，不是坏了。

**标记不会露出来**：剧情气泡、编辑框、导出的 txt/md/html、记忆正文里都会剥掉；
但库里保留 —— 记忆判定要读它。

## 二、表白：同一张卡累计，不再一条一条堆

以前"每种只记第一次"，被拒绝的那次会**占掉名额** —— 以后真成了反而不记。现在：

| 项 | 规则 |
|---|---|
| 次数 | 一直加（第 N 次表白）|
| 结论 | `被拒绝` / `已被接受`；后来接受了就**在同一张卡上改判**，不新开一条 |
| 理由 | 有词级理由就写理由，没有就用**她的原话**（前 1–2 句台词），最多留 3 条 |
| 正文 | 只留**最近一次**的对话；更早的交给「🔍 回顾」|

另外，只要有被拒的表白，提示词会在这一段末尾补一句：

> （被拒绝的表白只是「说过了」，关系没有因此确立：不要写成她已经答应、默许或「其实早就喜欢」）

这一句是专门治"越演越软"的。

**旧卡怎么办**：已经写进文件的旧卡不会自动重写（下次同类事件才会）；
但**注入的措辞会按正文重算**，所以提示词里不会再把"被拒绝"说成"态度未判定"。

## 三、新建分支：看得清自己在哪条线上

- 分叉节点下拉**按分支分组**了：主线一组、每条分支一组，组名就是分支名；组内按时间排，不再交错；
- 下拉换成**自绘**的：固定**向下展开**（原生控件在弹窗靠底时会向上弹，挡住刚填的分支名），
  盒子高度 28px、列表最高 220px 可滚、打开时把当前选中项滚进可视区；
- 选项回归干净的「第 N 天」（插曲带 🎭），不再需要「（分支内）」这种后缀。

## 四、冲突检测：三个假冲突 + 一条死规则

以前点「⚠ 冲突检测」，会出现「夏家老宅 与 夏家老宅 都在 (50,50)」这种报告。原因三条：

| 原因 | 后果 |
|---|---|
| **没有按分支过滤** | 建分支会整份复制世界观，同一个地点在主线和分支各一份 → 被当成两个地点抢坐标 |
| **没填坐标默认 (50,50)** | 两个都没填坐标的地点必然互相报 |
| **同坐标只取前两个** | 3 个地点只报 1 对，第三个静默丢掉 |

现在：只比**同一分支**、按**地图上的实际位置**判（没填坐标就按 50,50，和界面画的图钉一致）、
同坐标 N 个地点**两两全报**；「暂时忽略」也真的会隐藏（本次会话内，可一键恢复）。

顺手修了「🔍 检查」里一条**从来没触发过**的坐标规则（读的键名是 `map_x/map_y`，界面写的是 `x/y`）。

## 五、天数药丸条：共享历史只到分叉点

从第 6 天分叉出去之后，药丸条以前会显示「… 第 16 天 第 17 天 第 7 天 第 8 天」——
主线 16/17 天和这条分支毫无关系。现在只显示**分叉点及之前**的共享历史 + 本分支自己的天，
主线灰、分支用分支色，分叉点标 ★、分支第一颗标 ▸。
