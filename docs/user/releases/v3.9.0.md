# v3.9.0 — 开挂要结账，求她原谅也要先问她

> 发布 **2026-10-28** · 上一版 [v3.8.0](v3.8.0.md)
>
> 这一版的主题是「**让代价看得见**」：导演指令从"免费的强制推进"变成**记账的开挂**，

## 一、导演指令不再免费：她得在最后一行交代"凭什么松口"

**之前**：导演指令是"我说了算" —— 你写「让他答应」，模型就得照着演。
代价是零，所以开挂毫无阻力，读者也看不出她其实是被剧情硬拗的。

**现在**：只要这一轮用了导演指令，提示词就会要求 AI 在回复的**最后一行**写：

```
〔导演代价〕交换：他用母亲留下的地址换她开口
```

类型由她"在哪一步松的口"决定，**分值由软件算**（提示词里只有类型和口径，没有数字 —— 模型不碰数字）：

| 类型 | 含义 | 分 |
|---|---|---|
| 交换 | 用具体的东西或承诺换来（钱、情报、帮一次忙）| 5 |
| 条件 | 她提了条件，对方先做到 | 10 |
| 时限 | 只答应一段时间的尝试，随时可以退回 | 15 |
| 压力 | 被形势或第三个人逼到没有别的选择 | 20 |
| 心软 | 感情上撑不住（旧情、眼泪、受伤）| 25 |
| 白给 | 没有任何代价，她直接让了 | 30 |

- 理由最长 **32 字**，单次最高 **30 分**；同一本账（同一个分支 + 同一个 AI 扮演者）累计到 **60 分**，
  导演指令按钮就变 🔒（原因里会写「导演代价已累计 60/60」）。
- **一轮只结一笔**：模型写了收据就按收据记；它忘了写，软件才从正文里按关键词推断（同类型要命中 ≥2 个词，宁可漏记）；
  两者都有就**取更重的那笔**。表外类型 = **0 分、不记账**，只把那一行从正文里删掉。
- **自动扣关系强度**：只有「白给 **−10**」「心软 **−5**」两档扣（这两档她什么都没换到），夹到 0 不为负；
  交换 / 条件 / 时限 / 压力不扣 —— 她有对价，账已经记过了。扣完会当场提示，账本那行标「关系 −N」。
- **账本**在输入台底栏：「📒 导演账本 32/60」，点开是最近 30 条（天 / 类型 / 理由 / 分值）。
  每行可以「撤销」（直接删掉）或「赦免」（留痕、不计分）。**账本按钮不跟着闸门锁** —— 锁住的时候，正要靠它解锁。

> 为什么不让模型自己打分：模型对数字没有稳定的锚，"这次算多严重"它每次答得都不一样。
> 类型 → 分值这张表写在代码里（`director.rs::COST_KINDS`），测试锁着，改一个数字就要红。

## 二、赦免不再"一键消账"：要问过她

以前账本上的「赦免」点一下就生效 —— 等于自己给自己批条子。现在改成三段式：

1. 点「请求赦免」→ 弹窗里可以补一句话；
2. 请求变成一个**盒子**，挂在**当天最后一条消息**后面（不是独立页面、不进剧情历史，同一笔账最多 3 个）；
   盒子里写着：谁在请求 / 当时用的是哪条导演指令（**写明「当时的情况，不是现在」**）/ 她的回复模板 /
   你的补充 / 她的理由 / 她想对你说的话（可以不说）；
3. 她回 `〔赦免:同意〕` 或 `〔赦免:不同意〕` —— **同意才生效**，并把关系强度**回补一半**（−10 回补 5）。

- 同一笔账最多问 **3 次**；同一个**故事日**最多问 **5 次**（"一天"按故事里的天算，不是电脑日历）；
- 3 次都没同意 → 软件再扣 **5 点**关系（她的耐心用完了）；
- 「撤销」只对**已赦免**的账开放 —— 没被同意过就想撤，门都没有。

## 三、token 预算终于算准了（这版最"看不见"的改动）

旧口径是「**字数 × 1.5**」。它的问题在提示词改成中文以外之后暴露得很彻底：

- 英文同样一段话，**字数**是中文的约 2.5 倍 → 被当成 2.5 倍 token，实际只要 1/3 左右；
- 中文反过来又被高估 ~50%（1000 字算成 1500 token）。

后果不是"少算了钱"，而是**历史被提前裁掉**：预算显示"已经超了"，其实还有空间，模型于是忘掉了早期的剧情。

现在按**字符类别**加权（前后端同一套系数，`tokens.rs` / `parse.ts::estimateTokens`）：

| 字符 | 每个算多少 token |
|---|---|
| 汉字 / 假名 / 全角标点 / emoji | **0.79** |
| ASCII 字母数字 | **0.20**（≈ 5 字符 1 token）|
| 空格 / 换行 | 0.12 |
| ASCII 标点 | 0.39 |

然后**按真实 usage 校准**：请求带了 `stream_options.include_usage`，把上游返回的
`usage.prompt_tokens` / `completion_tokens` 回填进请求记录；参数页「Token 预算」现在会显示
「实测 / 估算（偏差）」和最近 50 条的平均倍数。

实测两轮（估算 5791 / 实测 4567、6315 / 4966）都**偏高 27%**，于是四个系数整体 ×0.787 ——
校准后 5 轮落在 **1.05~1.06**。剩下这 5% 是中英文比例不同带来的内容差异，**不再往 1.00 硬凑**（继续调只会过拟合这几条样本）；
参数页的提示阈值也放宽到 **1.10 / 0.90**，只有长期越界才值得再动系数。

> 这不是真分词器，是工程近似，而且**故意偏保守**（宁可略高、不要低估）。

## 四、基础指令与输出排版改英文

同一句约定用英文写，token 更省（见上一节）。这版把**基础指令**和**输出排版**两段的正文换成英文，
标题（`【…】`）和示例句仍留中文 —— 示例句是给模型照抄格式用的，翻成英文反而容易跑偏。

**行为约定一条没改**，只是换了叙述语言。

## 六、协议行的三个坑（这一版都填了）

| 坑 | 后果 | 修法 |
|---|---|---|
| 两条协议都要求"最后一行" | 同一轮里 `〔导演代价〕…` 与 `〔态度:接受〕` 撞车，收据被挤到正文中间 → **账没记**，记忆还判成"表白被接受"（其实她只是被逼让了一步）| 改成**末尾协议区**：各按自己的标记抓，谁在前谁在后都行 |
| 协议行进历史 | 这一轮没 injected 标记，模型却看见历史里有 → 每轮照着写，越写越像惯例；表外值（`〔态度:冷淡〕`）解析不了也不剥 → 露成气泡小方块 | 历史与回顾**都剥**；剥按**形状**（表外值也删）、解析仍严格 |
| 注入段写的是字段名 | 模型把「类型」「理由」当字面量照抄：`〔导演代价〕类型：条件：理由：…` → 类型读不出、理由超长 → 整笔账丢掉 | 注入段改成给**一行可照抄的例子**，并明确"不要自创词、不要写字段名" |

## 七、小而实的修正

- **老故事自动日摘要报** `no such column: day_summary_at` —— 这条迁移只在"建库"路径里跑过，打开已有故事时漏了，已补；
- 记忆正文里不再留空壳「**对方理由：**」（判定落在过滤前，理由被滤空后只剩标签）；
  没有词级理由时用**她的原话**（前 1–2 句台词），首次被拒的次数也记成 1；
- 赦免盒子的列表查询本身在报错（`LEFT JOIN` 后裸写 `branch_id` → `ambiguous column`），
  前端只拿到空数组，所以**盒子一直看不见**；改成带表别名，失败时把错误弹出来而不是只写 console；
- 她要是把判定标记写在**最前面**（模型常这么干），以前会判成「没看懂」、按钮卡在「等她回答」；现在认这一种写法；
- **演进分析只看这一轮**（以前拼最近 6 条，会把上一轮的「我爱你」和这一轮正文缝成"表白+接受"），
  并且**导演轮次只记事件、不提议数值**（开挂不该自动改关系强度）。
