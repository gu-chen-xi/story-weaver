# 安全检测说明（Security Verification）

> 面向：**不放心直接运行的人**，以及**愿意让它替你把关的 AI agent**（豆包 / DSH / Claude Code / Codex…）。
> 结论先放这：**本软件不开源以外的任何可疑行为**——不启动外部程序、不写注册表、不设开机自启、
> 不上报任何遥测。下面每一条都给了**可执行的核对方法**，你可以自己验，也可以把本文档丢给你的 agent 让它一条条跑。

## 一、为什么没有代码签名（直说）

安装包（MSI）和便携版 exe 都**没有代码签名** —— 有且只有一个原因：作者是学生、软件不赚钱、没人出证书钱。
**完整说明与 SmartScreen 跳过步骤见 [WHY-NO-CODE-SIGNING.md](WHY-NO-CODE-SIGNING.md) §一、§二**（本文件不重复）。

别信作者，信证据 —— 本目录三份文档，可以自己看，也可以直接交给 AI agent：

## 二、我们只验证了这三件事（都能用本节给的命令重现）

> 下面每条都是**核源码得出的结论**，不是对运行时的保证。运行时行为只有抓包能回答
> （[AGENT-AUDIT-GUIDE.md](AGENT-AUDIT-GUIDE.md) §3.3）。

三条结论（**命令与期望输出见 [AGENT-AUDIT-GUIDE](AGENT-AUDIT-GUIDE.md) §1~§3**，这里只给结论）：

1. **源码里没有"调用外部程序"的代码**（无 `Command::new` / `cmd /c` / `schtasks`）；
2. **源码里没有"持久化驻留"的调用**（无注册表 `Run` / 服务 / 计划任务 / 开机项）；
3. **源码里的外部地址只有两类**（外加测试夹具与文档链接）：
   * 你在「设置 → API」里填的**模型服务地址**（默认预置 DeepSeek：`https://api.deepseek.com`）；
   * 你在「立绘素材 → 生成参数」里填的**绘图服务地址**（默认本地 `http://127.0.0.1:7860`，或你自己配的云端）。
   清单里没有统计/埋点/上报域名 —— 但这**不代表**你机器上只会连这些（代理、DNS、系统级拦截都在我们视野外）。

> 若以上任何一条与你的实测不符 —— **请在 Issues 里贴证据**，作者会改。这比"信任"有用。

## 三、验证来源（重要：先验来源，再验行为）

没签名的包，"来源可信"这件事只能靠**两条**：

1. **哈希对得上**：发布页附带 `SHA256SUMS.txt`；你下载后自己算一遍，一致才继续。
2. **源码能自己编**：从本仓库 `main` 分支自己构建一遍，然后**对比行为**（不是对比字节 —— 见下）。

**为什么不比对哈希**：见 [WHY-NO-CODE-SIGNING.md](WHY-NO-CODE-SIGNING.md) §三。自己编一份、**比行为**才对（AGENT §3、§4）。

## 四、最快的一条路（如果你只想花 3 分钟）

> 📌 下文命令以 3.15.0 为例，按你实际下载的文件名替换版本号。

```powershell
# 1) 校验下载到的文件没被篡改（与发布页 SHA256SUMS.txt 对比）
Get-FileHash .\Story-Weaver_3.16.0_x64_en-US.msi -Algorithm SHA256

# 2) 看 exe 里有没有"外联"字符串（除了你自己的 API 地址，不该有别家域名）
#    （可选，需要 strings 工具；没有就跳过，用第 5 节的做法）
```

更推荐第 5 节的路子：**让 agent 直接读源码**。这个项目源码是公开的，
读源码比逆向二进制省事得多，也可靠得多。
