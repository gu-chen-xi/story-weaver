# 安全检测说明（Security Verification）

> 面向：**不放心直接运行的人**，以及**愿意让它替你把关的 AI agent**（豆包 / DSH / Claude Code / Codex…）。
> 结论先放这：**本软件不开源以外的任何可疑行为**——不启动外部程序、不写注册表、不设开机自启、
> 不上报任何遥测。下面每一条都给了**可执行的核对方法**，你可以自己验，也可以把本文档丢给你的 agent 让它一条条跑。

## 一、为什么没有代码签名（直说）

安装包（MSI）和便携版 exe 都**没有代码签名**。

原因很朴素：**作者是学生，这个软件不赚钱，作者自己也没钱整代码签名证书**
（一张 OV 代码签名证书一年几百到几千元，还要企业资质/个人实名审核）。

所以 Windows 在第一次运行时会弹 **SmartScreen**：

> 「Windows 已保护你的电脑」—— 发布者：未知

**可以直接跳过**：点「更多信息」→「仍要运行」。

如果你因此不放心，**这是完全合理的反应**。那就别信作者，信证据：
本目录下三份文档，可以自己看，也可以交给你的 AI agent。

## 二、三个"事实性"承诺（都可被本文档验证）

1. **不启动任何外部程序**：全仓库 `src-tauri/src/**` 里没有 `Command::new`、`cmd /c`、`powershell`、`schtasks`。
2. **不做持久化驻留**：不写注册表 `Run` 键、不装服务、不建计划任务、不改开机启动项；
   关闭窗口即退出进程。
3. **出站流量只有两类**：
   * 你在「设置 → API」里填的**模型服务地址**（默认预置 DeepSeek：`https://api.deepseek.com`）；
   * 你在「立绘素材 → 生成参数」里填的**绘图服务地址**（默认本地 `http://127.0.0.1:7860`，或你自己配的云端）。
   代码里没有硬编码的统计/埋点/上报域名。

> 若以上任何一条与你的实测不符 —— **请在 Issues 里贴证据**，作者会改。这比"信任"有用。

## 三、验证来源（重要：先验来源，再验行为）

没签名的包，"来源可信"这件事只能靠**两条**：

1. **哈希对得上**：发布页附带 `SHA256SUMS.txt`；你下载后自己算一遍，一致才继续。
2. **源码能自己编**：从本仓库 `main` 分支自己构建一遍，然后**对比行为**（不是对比字节 —— 见下）。

**为什么不能要求"字节一致"**：Rust/Tauri 的构建产物含**构建时间、绝对路径、编译器版本**等信息，
同一份源码在不同机器上编出来的 exe **哈希必然不同**。所以"可复现构建"在这里不成立，
任何人都做不到"hash 一致"——**声称能做到的才是可疑的**。

正确的做法是：**自己编一份，跑同样的操作，看行为是否一致**（AGENT-AUDIT-GUIDE 第 3、4 节）。

## 四、最快的一条路（如果你只想花 3 分钟）

> 📌 下文命令以 3.4.0 为例，按你实际下载的文件名替换版本号。

```powershell
# 1) 校验下载到的文件没被篡改（与发布页 SHA256SUMS.txt 对比）
Get-FileHash .\Story-Weaver_3.4.0_x64_en-US.msi -Algorithm SHA256

# 2) 看 exe 里有没有"外联"字符串（除了你自己的 API 地址，不该有别家域名）
#    （可选，需要 strings 工具；没有就跳过，用第 5 节的做法）
```

更推荐第 5 节的路子：**让 agent 直接读源码**。这个项目源码是公开的，
读源码比逆向二进制省事得多，也可靠得多。
