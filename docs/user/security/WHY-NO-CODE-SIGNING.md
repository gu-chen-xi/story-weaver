# 为什么没有代码签名（以及没签名时怎么自证清白）

> 这份文档只讲一件事：**签名缺失不是"藏着坏东西"，而是"作者没钱"**；
> 以及在没有签名的情况下，**你依然有办法验证你拿到的东西是干净的**。

---

## 一、作者的原话（照抄，不修饰）

> 作者是学生，这软件不赚钱，本身也没钱整代码签名，所以**签名就不整了**。
> 遇到了 Windows 弹警告，**可以直接跳过**。
> 如果不信任作者，**可以直接叫你的 agent（豆包、DSH、Claude Code 等）**
> 按 `docs/user/security/` 里的文档一点点对照检测有没有病毒。

这段话说得很直白，也可能让人不舒服 —— 但它是**真话**，而真话比"看起来很专业的空承诺"有用。

---

## 二、SmartScreen 弹窗长什么样、怎么跳过

第一次运行 `Story-Weaver_3.10.0_x64_en-US.msi` 或 `Story-Weaver.exe` 时可能出现：

```
Windows 已保护你的电脑
Microsoft Defender SmartScreen 阻止了无法识别的应用启动。
运行此应用可能会导致你的电脑存在风险。

            发布者：未知
            [更多信息]  [不运行]
```

操作：点 **「更多信息」→ 底部出现「仍要运行」→ 点它**。

> 这个弹窗的含义是「微软没见过这个文件、也没有签名能证明发布者身份」，
> **不是**「微软检测到病毒」。真有病毒会直接被 Defender 拦掉并报具体威胁名。

## 三、没签名时，"东西和我看到的一样"怎么核对

签名的本质作用是：*证明"这个 exe 确实来自这个作者、且发布后没被改过"*。
没有签名时，用**三重替代**：

### ① 哈希（防"下载途中被换包"）

发布页给出 `SHA256SUMS.txt`。你下载后自己算：

> 📌 下文命令以 3.10.0 为例，按你实际下载的文件名替换版本号。

```powershell
Get-FileHash .\Story-Weaver_3.10.0_x64_en-US.msi -Algorithm SHA256
Get-FileHash .\Story-Weaver-3.10.0-portable.zip -Algorithm SHA256
# 与发布页 SHA256SUMS.txt 里的对应行逐字符比对
```

不一致 = **别运行**，重新下载；还不对就来 Issues 报。

### ② 源码（防"作者偷偷塞东西"）

仓库是**公开**的：<https://github.com/gu-chen-xi/story-weaver>
编译方法在 `README.md` 第七节。**最关键的一点**：你编译时用的源码，
和发布包里 exe 的行为应当一致（见 ③）。

### ③ 自己编一份，比行为

```powershell
git clone https://github.com/gu-chen-xi/story-weaver.git
cd story-weaver
npm ci
npm run tauri build        # 产物在 src-tauri/target/release/
```

然后拿自己编的 exe 跑一遍同样的操作（新建故事 → 发一条消息 → 导出），
与发布版 exe 对比：

* 是否**都只**访问你配置的 API 域名；
* 是否**都**只在 `%APPDATA%\com.guchenxi.story-weaver` 下写数据；
* 是否**都**不驻留、不开机自启。

> **注意**：不要拿"哈希一致"当标准 —— Rust/Tauri 产物含构建时间与绝对路径，
> 换台机器编出来必然不同。要求"字节一致"是做不到的事。

### ④ 最省事：交给 agent 查

见 [AGENT-AUDIT-GUIDE.md](AGENT-AUDIT-GUIDE.md)。这个项目源码公开，
"读代码"比"逆向二进制"可靠得多，而 agent 最擅长读代码。

## 四、哪些"看起来可疑"其实很正常

| 你可能看到的 | 真实原因 |
|---|---|
| Defender 报「未知发布者」 | 没签名（本文档主题）|
| 安装时 UAC 提权 | MSI 默认装到 `Program Files`，需要管理员权限；**便携版不需要** |
| 程序访问网络 | 你配置的大模型 API（生成正文必需）|
| 程序读写 `%APPDATA%` | 你的故事/设定/立绘都存在那儿（见 [数据与备份.md](../数据与备份.md)）|
| 程序读取「凭据管理器」 | 你的 API Key 存在那里（**不写进任何文件**，见 `src-tauri/src/keys.rs` 头部注释）|
| 生成的图片左上角有「AI生成」字样 | **法规要求**（《人工智能生成合成内容标识办法》），故意不可关闭；服务方自己的水印保留在原位置（多在右下角），不覆盖 |
| exe 有十几 MB | Rust 静态链接 + WebView2 绑定，正常体积 |

## 五、如果你最终决定"还是不放心"

完全合理，而且有明确选项：

1. **只用源码版**：自己 `npm run tauri build`，不碰发布包。
2. **放进沙箱/虚拟机**试：Windows 沙盒（`Windows Sandbox`）或 Hyper-V 新建虚拟机，
   数据目录指到临时位置再跑。
3. **不要用**：这是你的电脑，你说了算；不需要为"不信任"找理由。

作者的态度：**这个软件不赚你钱，所以也没有立场要求你信任它。**
可验证 > 可信。
