## 1. 产品概述

单机桌面软件，用于 AI 辅助长文剧情创作（聊天/剧情生成）。

- **混合架构**：原生桌面应用框架 + Web UI 层，兼顾本地运行效率与 UI 表现力
- **纯本地**：本体纯本地部署与运行，唯一联网环节 = 用户配置并调用云端 API Key
- **插件化**：核心精简，扩展功能插件化（Ollama 本地模型、评估判断模型〔原 JEV〕等），用户自选安装启用
- **核心亮点**：设定"后台静默演进"——剧情 AI 只写故事，软件后台审阅剧情、判断设定是否实质性变化、生成变更提案、人工确认后更新快照，后续剧情基于新设定续写

## 2. 技术形态与架构（规划）

| 层 | 技术 | 说明 |
|----|------|------|
| 桌面壳 | Tauri 2（Rust） | 壳 + 核心逻辑 |
| UI | React + TypeScript + Vite（内联样式，深色 STORY DECK 主题） | Web UI 层 |
| 数据库 | SQLite（sqlx） | library.db（库索引/共享）+ 每故事 story.db |
| 状态管理 | React useState / 组件内状态（未引入状态库） | 前端状态 |
| Token 估算 | 前端字符粗估 + N 值自适应降级 | 上下文预算 |
| 网络 | reqwest + tokio | 云端 API 调用 |
| 本地模型 | Ollama / llama.cpp（插件） | 用户自选启用 |
| 云端模型 | OpenAI-compatible | 用户配置 Key 后使用 |
| 分析器 | Rust 规则引擎（段落归属 + 代词回指）；模型辅助 / 插件后置 | 后台演进/状态提取 |

架构分层：

```
┌─────────────────────────────────────┐
│  UI 层（React + TS + Vite · 内联样式）│ ← 12 个必备页面
├─────────────────────────────────────┤
│  核心层（Rust：剧情/上下文/时间线/演进）│
├─────────────────────────────────────┤
│  存储（SQLite：library.db + story.db）│
├─────────────────────────────────────┤
│  分析器（Rust 规则引擎，模型辅助后置）  │
└─────────────────────────────────────┘
```

联网边界：仅云端模型调用（用户配置 Key 后）；插件（Ollama / 评估判断模型 / 立绘生图）由用户安装启用。

## 4. 功能规格

### 4.1 故事与时间线（核心骨架）

- 创建故事时弹出**故事开幕**弹窗：设定**绝对时间起点**（现实日期或架空纪元）；起点固定后"X 天后"由系统自动计算，AI 只填内容
- **按日存储**剧情（timeline_nodes）；日历视图（滚动型 UI，用户视角），后台转 AI 易读格式
- **插曲/倒叙**：空白日期右键"插入插曲"→ 自动打"倒叙/回忆"标签 + AI 附加时空提示
- **修改历史剧情**：用户修改后 AI 后续严格基于修改后结果续写；大幅修改弹出**蝴蝶效应预览**，对比新旧分支，用户手动选择保留哪条
- **局部化统计**：标签管理与数据统计**绑定对应时间线/日期节点**，跟随时间线走，不做全局统计（避免剧情割裂）
- 修改历史 → 标记后续失效 → 重新分析（见测试用例负例"历史修改"）

### 4.2 角色与世界观

- 角色库：增删改查、初始设定、当前状态（characters.version 版本化）
- 角色档案字段（A/G 版面）：alias / role / faction / age / gender / first_appearance / one_liner / profile / speech_style / traits + 体力 / 理智 / 情绪 / 戏份四条属性；说话方式、身份与小传注入剧情 AI
- 关系图：增删改查，relation_type / direction / strength / state / active_from / active_to / version；右侧图谱为父节点中心两层布局（父节点可切换，0938801）
- 世界观：条目管理 + **硬规则标记**（is_hard_rule，冲突校验依据）

### 4.3 剧情生成

- 输入框 + **三重语法**：`（圆括号）`=动作/表情/心理 · `"双引号"`=台词 · `裸文本`=元指令（最高权限）
- **元指令拦截**：裸文本绝不进入正式剧情上下文；发送后转化为带"齿轮/铅笔"图标的**金色横幅**视觉区隔
- **双模式**：🎭 沉浸式扮演（代入式，AI 扮演角色回应，时间随对话流动）⇄ 🎬 上帝视角扩写（导演式，大纲→大段扩写）——切换位于**底部输入台工具胶囊栏**（仿聊天软件工具条）
- 调用模型 + **流式输出** + 保存到当前时间节点（messages + timeline_nodes）

### 4.4 上下文管理（核心底层逻辑）

- **上下文顺序**（最小MVP实现.md §6）：系统提示词 → 角色设定 → 关系图 → 世界观 → 最近 N 轮对话 → 当前用户输入
- **绝对不截断区**：系统提示词（最高）、人物设定（第二高）、角色关系图、世界观——这四部分**绝不参与**压缩/截断
- **动态上传策略**：关系图、世界观是否上传由系统智能判断（当前剧情节点的相关性或 Token 余量），不全量发送
- **只截断历史**：仅"AI 历史生成 + 用户历史输入"可截断
- **N 值自适应**：实时读取当前模型最大上下文窗口；自定义 N 濒临超限时自动向下调整 N，保证请求合法不报错
- **输入台 Token 占比**：对话区底部输入台实时显示当前时间线节点的 Token 预算占比（数据=该节点最近请求快照，逻辑同「生成参数 › Token 预算」；发送后自动刷新）
- 截断只丢历史不做摘要（角色对话场景）；超限触发 E4

### 4.5 状态提取与状态卡

- 从自然文本提取情绪/动作/神态：**规则优先**，模型辅助（轻量级判断插件可接入）；提取源 = 最新 AI 回复 + 最新用户输入（用户输入也是剧情内容的一部分，3405da5）
- 提取情绪标签（如 `[Angry]`）→ **无需重新生图**，UI 层直接为立绘叠加动态效果（红框、气泡）→ 状态卡更新
- 剧情 AI 输出要求：Prompt 强制"必须自然包含动作变化、心理活动、神态描写"（**状态包含性**，替代死板 JSON/标记格式）

### 4.6 后台静默演进（核心亮点）

**职责分离**：剧情 AI 不参与设定的判断和修改；软件后台（规则引擎/独立分析模型）审阅。

完整链路（对应测试用例.md 主用例）：

```
剧情生成完成（写入当日节点）
  → 后台异步分析器读取：设定快照 + 关系图 + 当日剧情 + 时间线节点
  → 提取候选事件（置信度 ≥ 0.8）
  → 判断是否实质性改变设定
  → 生成变更提案（target/字段/旧值/新值/原因/证据/置信度/生效时间/可逆性）
  → 校验（字段合法/数值越界/世界观冲突/关系冲突/证据充分/置信度/冷却期/高风险）
  → 策略：关系强度可自动；关系类型需人工确认
  → 用户确认/拒绝 → 应用变更 → 生成新快照（parent_version 链接）
  → 写入审计日志 → 关系图更新 → 后续剧情 AI 读取新快照
```

- 回滚：沿快照 parent_version 链回退（可回滚到 V10）
- 冷却期：3 天内不自动应用重复变更（只记录）
- 冲突：校验拒绝并提示（如"B 是 A 妹妹"与"交往"并存）

### 4.7 设置与安全

- **API Key 安全隔离**：系统钥匙串存储，**绝不保存在剧情文件夹内**；不上传、不给第三方读取
- 模型参数（温度等）
- **缓存管理**：可视化面板展示各文件夹缓存内容；用户自定义总容量上限（**默认 5GB**）；超限自动清理 + 手动选择性删除

### 4.8 调试与日志

- 请求日志 / Token 使用 / 上下文组成 / 分析器结果 / 变更提案 / 错误日志 → 日志与调试面板

## 6. AI 上下文与提示词

### 系统提示词必须包含
- 角色身份、当前关系、世界观
- 关系注入句式：单向 = A 是 B 的「关系类型」；双向 = 自动拆成两条单向（亲属词父女/父子/母女/母子/兄妹/姐弟：先按性别判长辈，同性按年龄，判不出用 from 兜底；其他词拆成两条同类型；空类型默认 A 和 B 是陌生人）
- 输出要求：必须自然包含动作、心理、神态
- 不得输出 JSON 或死板格式；不得自行修改设定

### 上下文顺序
1. 系统提示词 → 2. 角色设定 → 3. 关系图 → 4. 世界观 → 5. 最近 N 轮对话 → 6. 当前用户输入

### 截断策略
- 绝对不截断：系统提示词、人物设定、关系图、世界观
- 只截断：AI 历史生成 + 用户历史输入
- 超限自动降 N；动态决定是否上传世界观和关系图

## 8. 异常与边界

### 异常对照表

| # | 异常 | 触发条件 | 处理策略 |
|---|------|----------|----------|
| E1 | 空输入 | 发送空内容 | 禁止发送，提示 |
| E2 | 语法未闭合 | 括号/引号未闭合 | 提示位置，不提交 |
| E3 | 模式冲突 | 上帝模式输入角色台词 | 按上帝模式规则并入剧情 |
| E4 | Token 超限 | 上下文濒临超限 | 自动降 N / 动态不上传关系图与世界观；仍超提示 |
| E5 | 模型不可用 | 未配置 Key / 超时 / 网络错误 | 错误提示 + 保留输入可重试，不丢数据 |
| E6 | 提案校验失败 | 字段非法/越界/世界观冲突/关系冲突 | 拒绝提案并提示原因 |
| E7 | 冷却期内重复变更 | 3 天内同类变更 | 不自动应用，只记录 |
| E8 | 低置信度 | 候选事件置信度 < 0.8 | 忽略，不生成提案 |
| E9 | 回滚不可用 | 快照链缺失 | 禁用回滚并提示 |
| E10 | 存储写入失败 | 磁盘/权限问题 | 报错，数据保留在内存提示另存 |
| E11 | API Key 缺失 | 未配置即调用云端 | 引导到设置页 |
| E12 | 缓存超限 | 超过用户设定上限（默认 5GB） | 自动清理最久未用缓存 |

### 边界条件表

| 项 | 边界值 | 说明 |
|----|--------|------|
| 分析器置信度阈值 | 0.8 | 低于忽略（E8） |
| 变更冷却期 | 3 天 | 期内不自动应用（E7） |
| 缓存上限 | 默认 5GB | 可自定义（E12） |
| 关系强度 | 0-100 | 越界校验拒绝 |
| 关系类型/方向 | 人工确认 | 高强度变更需确认 |
| N 值（保留轮数） | 随模型窗口自适应 | 濒临超限自动降 |
| 绝对不截断区 | 4 类内容 | 永不压缩/截断 |
