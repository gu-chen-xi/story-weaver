# UI_TREE · UI 组件树

> 项目版本：**V2.2**（2026-10-16）｜本文档最后同步：2026-10-16

> AI 剧情创作软件界面按钮 / 组件完整层级（随实际实现实时同步）。
> 类型标注：`[btn]` 按钮、`[input]` 输入、`[list]` 列表、`[card]` 卡片、`[bar]` 状态条、`[label]` 文本、`[modal]` 弹窗、`[tab]` 标签页、`[toggle]` 开关、`[icon]` 图标、`[chip]` 标签、`[placeholder]` 占位符。
> 对应：Tauri 2 + Rust + React + TS（技术栈）；主界面 = 深色 STORY DECK 三栏导演工作台；品牌：窗口壳 = 织梦机，左栏 / 打包名 = Story-Weaver。

---

## 0. 根（全局布局，2026-09-27 V3.0 按当前实现重写）

```
App（主窗口，Windows 套壳，深色主题）
├── ① TitleBar 顶部标题栏（极简，右侧原生窗口控制：— / □ / ✕）
├── ② LeftNav 左侧导航（固定 200px，剧情区 / 扩展工程区 两个独立盒子）
├── ③ Center 中间主工作区（Flex-1，view 机制切换页面）
└── ④ RightPanel 右侧导演监视器（固定 300px）
```

- 三栏横向布局；无独立底部通栏输入台——输入区内置在中间主工作区下半部。
- 页面切换由 `view` 状态驱动：`home | stories | story | timeline | chars | world | relations | proposals | plugins | portrait | params | debug | cache`；初始 `home`。

### 3.7 params（生成参数页，2026-10-02 新增）

```
ParamsPage
├── 页头：🎛 生成参数 · 《故事名》· 模型 / 上下文窗口 / 当前快照（#id · 节点 / 第 X 天 · 时间 · N 条）· 快照选择器（默认跟随当前时间线节点）· 🔄 刷新快照 [btn]
├── TabSeg：📊 Token 预算 / 🧾 Prompt 预览 / 🎨 立绘参数 / 🧩 JSON
├── Token 预算：总预算条（system 各段 / 上下文更新块 / 历史 / 本次输入 / 剩余）+ 装配清单表（注入内容 / 占用比例 / Token / 裁剪优先级）；历史行标注「不含本次输入」
│   └── 段名由【】标记切分。**提示词分两处**：① system（稳定前缀，跨轮不变，便于前缀缓存）：基础指令 + 输出排版 / 数据字典 / 世界观 / 角色 / 方向和关系；② 尾部「上下文更新」块（易变，插在历史之后、本次输入之前，每轮单独拼装、不落库）：当前模式（含导演指令）/ 篇幅要求 / 数值与状态 / 本次聚焦 / 剧情约束 / 时空提示。**正文里含【】的说明文字会被误切成独立段，故提示词内部小标题一律不用【】**（数据字典内的强度档位图例即按此规则书写）
├── Prompt 预览：按来源分色展示实际拼装内容（system 各段 / 历史 / 上下文更新（尾部）/ 本次输入）+ 复制完整 Prompt + token / 状态页脚；关系拆两段呈现：**方向和关系**（A 是 B 的「X」+ 方向 + 说明，进 system）与**数值与状态**（强度 83（羁绊）｜状态：稳定，进尾部块，带「以本节为准」覆盖声明）；双向自动拆成两条单向（亲属词按性别 / 年龄判长辈，非亲属词拆两条同类型，空类型默认「A 和 B 是陌生人」）；N 以「条消息」计（含本次输入）
├── 立绘参数：三栏排版（左=模型与采样：模型名 / Steps / CFG / Seed+🎲，LoRA 占位；中=正面 / 负面提示词、尺寸比例、角色一致性锁定（参考已绑定立绘，denoise 后置）、输出格式 / 张数占位；右=素材预览 + ✨ 生成 4 张（后置）/ 💾 保存参数 / ↩ 恢复）
│   └── 参数对象：素材下拉（portraits）；保存调用 portrait_update_params，与素材详情页生成参数同步
├── JSON：最近一次请求的完整 JSON（复制）
└── 无故事：空态引导「去故事列表」；无快照：提示先发送剧情消息
```
