## 二、各区域规格

### ① 顶部标题栏（极简）

- 左：Logo + 软件名；中部：当前连接模型名 · 当前故事名 · 当前时间点（第 X 天）
- 右：标准窗口控制按钮（最小化 — / 最大化 □ / 关闭 ✕）——采用 Tauri 原生标题栏
- 视觉：深色底、极简；模型名实显（不再写死"模型已连接"）

### ② 左侧导航（固定 200px，两个独立盒子）

- **左栏品牌区**：Story-Weaver / 剧情导演工作台（原生窗口标题 = 织梦机）
- **剧情区盒子（上半）**：
  - 无故事（首页）：仅 📁 故事列表
  - 进入故事后：📁 故事列表 · 📅 时间线 · 👥 角色管理（内含「关系设定」子区） · 🌍 世界观设定 · 📋 演进提案（待确认红点） · 🖼 立绘素材
- **扩展/工程区盒子（下半，与剧情区视觉分离）**：🧩 插件（占位页）+ ⚙️ 设置（固定左下角）
- **生成参数入口**：🎛 生成参数（固定位于「立绘素材」下方；点击进入 params 页：Token 预算 / Prompt 预览 / 立绘参数 / JSON）
  - 首页时扩展区在故事列表下方；进故事后在立绘素材下方
- 选中项高亮；折叠为纯图标列（宽 48px）能力保留

### ③ 中间主工作区（Flex-1，view 机制）

- **首页（home）**：空白，不显示任何内容
- **故事列表页**：新建故事（开幕弹窗设时间起点）/ 刷新 + 故事卡片（进入/删除）
- **主剧情界面**：
  - 对话区（独立滚动）：用户消息右对齐深色气泡；AI 消息剧本渲染（旁白浅灰 / `[角色名]“台词”` 橙色角色标签 / 括号动作斜体灰 / `*……*` 心声暖玫瑰斜体带左竖线；流式打字机）；按日分隔标签；元指令金色横幅；剧情内时间戳
  - 底部输入台：旁白/对话两态切换（对话模式含 我扮演/AI扮演 下拉，默认 男主/女主；**导演指令 chips** 仅对话模式可用、一次性生效）· 敏感词过滤 · 剧情约束 · 篇幅 **简单/详细**（两挡，2026-10-08 起）· 记忆上下文开关 · @角色 / #标签 · 输入框（Enter 发送）· 橙色提交按钮 · 右下角当前节点 Token 预算占比迷你条
- **立绘素材页**：页头统计+动作按钮（✨ AI 生成立绘 后置提示 / 📤 导入本地 已实装 / ＋ 新建素材 已实装）、工具栏（搜索/角色筛选/排序/视图切换 网格·列表·瀑布·分组）、四视图、勾选批量操作条（移动分组/打标签/导出/删除，已实装）、分组视图按 group_name 聚合（未分组兜底+组内预填）、详情页（信息kv/角色可编辑/表情差分·主色卡 占位/生成参数 实装/版本历史 实装）、空态
- **生成参数页**：四页签（Token 预算：请求快照拆分 + 装配清单；Prompt 预览：按来源分色 + 复制；立绘参数：三栏排版，素材参数保存写回；JSON：最近请求完整 JSON），排版参考原型-生成参数排版-v2；页头快照选择默认跟随当前时间线节点、可切换；N 按「条消息」显示
- **管理页**：时间线（列表/日历月视图）/ 角色管理（A 卡墙 / D 关系网络 / G 新建编辑）/ 世界观 / 提案（确认/拒绝/回滚）/ 插件占位 / 调试 / 缓存

### ④ 右侧导演监视器（300px，从上到下三块）

| 区块 | 内容 | 形式 |
|------|------|------|
| 立绘图区 | 角色立绘绑定联动（按 story_id + character_id 匹配已绑定素材：真图横排 + 情绪滤镜 M5 徽章/边框光晕，未绑定 🧑 占位；点击立绘卡 = 切换焦点角色；已绑定卡 ⛶ = 跳素材详情；＋ 跳素材库） | 卡片 · 实装 |
| 角色卡区 | 焦点角色详情卡（点击右侧立绘切换）：头像 + 名字 + 焦点徽章 + 情绪标签 + 状态文字 + 关系摘要（箭头 / 类型 / 强度 / 方向）+ 角色设定；底部属性条 / Buff 占位 | 卡片 · 真实数据 |
| 关系图 | 父节点中心两层布局（实装）：角色 chips 切换父节点（默认焦点角色）、中心橙圈 + 外围直接关联角色、单向箭头 + 类型/强度标签，与关系设定联动；双向反向虚线后置 | 卡片 · 实装 |
| 剧情分支预测 | 【占位符】 | 卡片 · 后置 |

### ⑤ 设置弹窗（左下角 ⚙️ 点击后弹出）

- **API 设置**：模型 BaseURL / 模型名 / API Key（钥匙串存取，不落项目目录）/ 模型参数
- **请求日志**：请求快照调试记录器（每次请求完整上下文，点击单条查看提交内容）
- **数据管理**：缓存管理（占用 / 上限默认5GB / 自动清理 / 清空）+ 故事数据

## 四、交互与异常反馈

- 空输入 / 语法未闭合（E1/E2）：输入框下方提示，不提交
- 模型不可用（E5）：保留输入可重试
- Token 超限（E4）：自动降 N，提示
- 有待确认提案：左导航「演进提案」红点
- 立绘素材：视图切换/搜索/筛选/勾选批量/详情实时响应；仅 AI 生成立绘按钮点击后 toast 提示"后置（规划中）"
- 右侧立绘卡：点击 = 切换焦点角色（角色卡联动刷新）；已绑定立绘卡的 ⛶ = 跳素材详情

## 五、设计原则

- **深色 STORY DECK**：窗口 #16181d / 面板 #1c1f26 / 强调色 #FF7A18；卡片圆角、弱边框、聚焦橙描边发光
- **尺寸比例**：左 200px 固定 / 中间 Flex-1 / 右侧 300px；上下区 7:3（对话区 : 输入台）
- **对齐与层级**：气泡左右分明、导航垂直等距（剧情区/扩展区两盒子分离）、设置按钮固定左下角
- **占位符区分**：虚线框 + 深灰底 + 文字标注，与真实功能块视觉可辨
