## 1. 技术栈与载体

- 形态：**Windows 单机桌面应用**（V1.0，仅 Windows，无多用户协作，数据集中根目录）
- 品牌：窗口标题 = **织梦机**；左栏品牌 / Tauri 打包名 = **Story-Weaver**（2026-10-02）
- 桌面壳：**Tauri 2（Rust 核心）已确认落地** + React + TypeScript + Vite + SQLite（sqlx）
- 前端 UI：深色 STORY DECK 三栏导演工作台，**内联样式**（未引入 Tailwind CSS / Zustand）
- 数据：本地 **SQLite**（story.db / library.db），目录规划见根目录《STORAGE.md》
- Token 估算：前端字符粗估 + N 值自适应降级（未引入 tiktoken-rs）
- 模型接入：云端 API **原生内置**（OpenAI-compatible，DeepSeek 已验证）；Ollama 本地模型走插件（后置）
- API Key：系统钥匙串（keyring / Windows 凭据管理器），绝不落项目目录
- 说明：早期原型曾用 Electron + 原生 HTML/CSS/JS，已废弃重规划；Tailwind / Zustand / tiktoken-rs 曾在规划中提及，最终未落地

## 6. 常用命令

```powershell
cd D:\project\ai生成
npm run tauri dev          # 启动开发（隐藏窗口方式见下）
npm run build              # 前端 tsc + vite build

git log --oneline          # 查看提交历史
git tag v0.1               # 里程碑打标
```

- 云端 API：**原生内置**（Rust generate.rs，OpenAI 兼容 chat/completions，默认 DeepSeek：base_url https://api.deepseek.com/v1，model deepseek-v4-flash），流式 SSE 逐字输出

- 上下文组装：系统提示词 + 人物设定 + 关系图 + 世界观（不截断）+ 最近 N 轮（可降 N）
- Ollama 本地：**插件**（后置，插件系统本体未做）
- 请求快照调试器：debug_requests 表，设置弹窗"请求日志"内查看单次完整提交内容
