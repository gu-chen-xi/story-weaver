## 四、存储模型过期（STORAGE / SPEC / 开发规范 / PLAN）

### 旧说法

> "所有数据集中在根目录 `D:\project\ai生成\`"，列出
> `app/ resources/ config/ library/ plugins/ models/ cache/ logs/ backups/ temp/ exports/`

### 真相（`src-tauri/src/paths.rs`）

数据在**一个数据根**下，根的位置**按可写性逐级探测**：

```
① DREAMWEAVER_DATA_DIR（显式指定；不可写时也继续兜底）
② %APPDATA%\com.guchenxi.story-weaver
③ %LOCALAPPDATA%\com.guchenxi.story-weaver
④ <exe 同级>\data            ⑤ <exe 同级>\dreamweaver-data
⑥ <当前目录>\data → 系统临时目录
根下只用：library/ exports/ temp/ logs/ backups/
```

> 必须探测可写的原因：实测某机器上程序**连新建目录都被拒**（安全软件拦截，`os error 5`），
> sqlite 报 `attempt to write a readonly database`，应用起不来 —— 而**同一台机器 Python 能写**。
> 所以"目录看起来在"不能作为依据，改成**真写一个探针文件**判定。

### 逐项核实

| 旧文档说法 | 实际 | 代码引用数 |
|---|---|---|
| 根目录 `library/` 是故事库 | 数据在数据根下；根目录 `library/` 已迁走 | — |
| `config/` 存全局配置 | **已废弃** —— 配置在 `library.db` 的 `configs` 表 | **0 处** |
| `plugins/installed/` + `plugins/data/` 存插件 | **未实现**（插件体系在后续批次） | **0 处** |
| `models/` 存本地模型 | **未实现**（立绘走 SD WebUI API / 云端） | **0 处** |
| `resources/` 内置资源 | **未实现** | **0 处** |
| `cache/` + `cache_entries` | 目录空壳；表**从未写入** | **0 处** |
| `app/` 放打包产物 | 空目录，**未打包** | **0 处** |
| `story.db` "12 张表" | 实际 **14 张**（增 `cache_entries` / `story_summaries` / **`branches`**） | — |
