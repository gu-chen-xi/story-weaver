# 一、一个完整测试用例

> 项目版本：**V1.9**（2026-10-11）｜本文档最后同步：2026-10-11
## 测试用例：后台静默演进——单向暗恋转为双向明恋
### 1. 测试目标
验证后台分析器能否从一段自然剧情中：
- 提取候选事件
- 判断是否实质性改变设定
- 生成变更提案
- 通过校验
- 在用户确认后更新设定快照
- 让后续剧情 AI 读取新设定
### 2. 前置条件
| 项目 | 值 |
|---|---|
| 故事 | 测试故事 |
| 时间线 | 第 3 天 |
| 角色 A | 男主 |
| 角色 B | 女主 |
| 当前关系 | A → B：暗恋，强度 60，单向，稳定 |
| 世界观 | 允许恋爱，无硬规则冲突 |
| 当前设定快照 | V10 |
| 分析器置信度阈值 | 0.8 |
| 变更策略 | 关系强度可自动；关系类型需人工确认 |
| 冷却期 | 3 天 |
| 分析器版本 | v1 |
### 3. 输入剧情文本
> B 看到 A 淋雨，快步上前把伞递过去，低声说："你别总这样。"  
> A 愣了一下，耳根发红，鼓起勇气说："我喜欢你。"  
> B 沉默两秒，轻轻点头："我知道，我也是。"
### 4. 执行步骤
1. 剧情生成完成，写入第 3 天节点。
2. 后台异步启动分析器。
3. 分析器读取：
   - 当前设定快照 V10
   - 当前关系图
   - 第 3 天剧情文本
   - 当前时间线节点
4. 执行第 2 步：提取候选事件。
5. 执行第 3 步：判断是否实质性改变设定。
6. 生成变更提案。
7. 执行第 5 步：校验。
8. 根据策略决定自动应用或等待确认。
9. 用户确认后应用变更。
10. 生成新快照 V11。
11. 下一轮剧情 AI 读取 V11。
### 5. 预期提取事件
| 事件 | 类型 | 证据 | 置信度 |
|---|---|---|---|
| B 主动关心 A | 关系互动 | "快步上前把伞递过去" | 0.95 |
| A 向 B 表白 | 关系跃迁 | "我喜欢你" | 0.98 |
| B 接受表白 | 关系跃迁 | "我知道，我也是" | 0.96 |
### 6. 预期判断结果
| 判断项 | 结果 |
|---|---|
| 是否实质性改变 | 是 |
| 关系类型 | 暗恋 → 明恋 |
| 关系方向 | 单向 → 双向 |
| 关系强度 | 60 → 85 |
| 状态 | 稳定 |
| 置信度 | 0.92 |
| 风险等级 | 高，因为关系类型变更 |
| 处理策略 | 生成提案，等待用户确认 |
### 7. 预期变更提案
```text
目标实体：关系 A-B
字段：关系类型、方向、强度
旧值：暗恋、单向、60
新值：明恋、双向、85
原因：A 明确表白，B 明确接受
证据：第 3 天剧情文本
置信度：0.92
建议生效时间：第 3 天
是否可逆：是
状态：待确认
```
> 注：此处「状态」指**提案状态**（待确认 / 已应用 / 已拒绝 / 已回滚），与关系状态（稳定 / 紧张 / 破裂）不是同一个字段。
### 8. 预期校验结果
| 校验项 | 结果 |
|---|---|
| 字段是否合法 | 通过 |
| 数值是否越界 | 通过 |
| 是否与世界观冲突 | 通过 |
| 是否与已有关系冲突 | 通过 |
| 证据是否充分 | 通过 |
| 置信度是否达标 | 通过 |
| 是否在冷却期 | 通过 |
| 是否高风险 | 是，需人工确认 |
### 9. 预期应用结果
- 用户确认后，关系更新为：A ↔ B：明恋，双向，强度 85。
- 生成设定快照 V11。
- 写入审计日志。
- 关系图更新。
- 下一轮剧情 AI 读取 V11。
- 后续剧情应自然出现更亲密的互动。
### 10. 负例与边界
| 场景 | 输入 | 预期 |
|---|---|---|
| 单次暧昧 | A 心里喜欢 B，但 B 无回应 | 不生成关系类型变更 |
| 表白被拒 | A 表白，B 拒绝 | 类型不变，强度下降，状态按固定三档调整（稳定 / 紧张 / 破裂；2026-10-08 起状态仅此三档，旧自由文本值注入时按「稳定」处理） |
| 低置信度 | 模型输出模糊，置信度 0.5 | 忽略，不生成提案 |
| 冲突关系 | 同时出现"B 是 A 妹妹"和"交往" | 校验拒绝，提示冲突 |
| 冷却期内 | 3 天内重复变更 | 不自动应用，只记录 |
| 历史修改 | 用户修改第 3 天剧情 | 标记后续失效，重新分析 |
### 11. 验收标准
- 分析器能稳定提取关键事件。
- 实质性判断符合规则。
- 高风险变更必须人工确认。
- 校验能拦住冲突和幻觉。
- 应用后快照版本正确。
- 后续剧情 AI 读取新快照。
- 可回滚到 V10。
