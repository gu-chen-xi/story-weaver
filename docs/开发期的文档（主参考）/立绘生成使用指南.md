# 立绘生成 · 使用与测试指南

> 面向"没有本地绘图服务"的情况。三条通道任选其一即可出图；**没有绘图服务也完全不影响**素材库与角色管理。

---

## 一、先搞清楚三条通道

| 通道 | 需要什么 | 适合谁 |
|---|---|---|
| **本地 SD WebUI** | 本机装 Stable Diffusion WebUI 并带 `--api` 启动 | 有独显（建议 ≥8G 显存）、想完全离线、不在乎折腾 |
| **云端 · 兼容 OpenAI Images API** | 一个"接口形状像 OpenAI"的云服务 + API Key | 手上有这类服务的人（最省事） |
| **云端 · 自定义 URL + 请求模板** | 任意云服务的接口文档 + API Key | **手上有别的云服务（即使用硅基流动这类"接口不标准"的）** |

**你现在的情况**（本机没装 SD WebUI）：走云端。**推荐用「自定义模板」通道**，因为国内多数云服务（含硅基流动）的图片接口与 OpenAI 的形状不同。

---

## 二、用「自定义模板」接硅基流动（可照抄）

### 第 1 步：拿 API Key

1. 打开 <https://cloud.siliconflow.cn/> 注册（手机号即可）
2. 左侧「API 密钥」→ 新建密钥 → 复制（形如 `sk-xxxx`）
3. 新账号一般有赠送额度；首充还会翻倍（以官网实际活动为准）

### 第 2 步：在软件里填

「插件 / 扩展」→ **立绘生成** → 点「打开面板」→ 通道选 **云端 · 自定义 URL + 请求模板**：

| 字段 | 填什么 |
|---|---|
| **请求地址** | `https://api.siliconflow.cn/v1/images/generations`（国际域名：`https://api.siliconflow.com/v1/images/generations`，两者都可用） |
| **响应字段路径** | `url:images.0.url`（`url:` 前缀 = 该字段是图片链接，软件会去下载后入库） |
| **鉴权方式** | 选 **Authorization: Bearer** |
| **API Key** | 粘贴你的 `sk-…`，然后点「保存到配置」 |
| **额外请求头** | 一般留空（**不要**用请求头去关掉服务方的 AI 生成水印，理由见第七节） |

**请求体模板**（整段复制粘贴）：

```json
{
  "model": "Kwai-Kolors/Kolors",
  "prompt": "{{prompt}}",
  "negative_prompt": "{{negative}}",
  "image_size": "768x1024",
  "num_inference_steps": 20,
  "guidance_scale": 7.5,
  "seed": "{{seed}}"
}
```

> ⚠️ `image_size` 必须写成 `宽x高` 的字面值，**不能用 `{{width}}x{{height}}`** ——
> 模板只做文字替换、不会做算术或拼接。改尺寸就直接改这段文字（例如 `960x1280`）。
> 常用值：`1024x1024`(1:1)、`960x1280` 或 `768x1024`(3:4，立绘最合适)、`720x1280`(9:16)。

### 第 3 步：检查配置 → 生成

1. 点 **「检查配置」** → 应显示"配置齐了（自定义形态只在真正生成时才会请求服务，避免误触计费）"
2. 填提示词（例如 `1girl, nun habit, silver hair, standing, upper body, soft light`）
3. 「入库为角色」选一个角色 → 点 **「✨ 开始生成并入库」**
4. 成功后会显示：`✅ 已入库 1/1 张：xxx（v1）（已绑定该角色）`，并直接出现在「立绘素材」与角色卡上

### 常用模型名（以[官方生图模型页](https://cloud.siliconflow.cn/models?types=to-image)为准，会变动）

| 模型名 | 备注 |
|---|---|
| `Kwai-Kolors/Kolors` | 支持负向提示词与 guidance_scale，中文提示词友好，**推荐先用这个** |
| `Qwen/Qwen-Image` | 质量好；**不支持 negative_prompt / guidance_scale**，改用 `cfg`；尺寸建议 `1056x1584`(2:3) 等官方推荐值 |
| `Qwen/Qwen-Image-Edit-2509` | 图片编辑（要传 `image` 参考图），**不能用来纯文生图** |

### 「响应字段路径」怎么确定的

1. 官方文档的响应用例里，图片链接在 `images` 数组的元素 `url` 字段（返回的是**有效期 1 小时的临时链接**，软件会立刻下载入库）
2. 接口连通性实测过：不带 Key 请求两个域名都返回 `HTTP 401 {"code":30014,"message":"Token is invalid."}` —— 说明地址与鉴权方式（`Authorization: Bearer`）正确，**只差你的 Key**

如果将来官方改了字段名，生成时软件会明确报 `响应里找不到路径「url:images.0.url」`，
你只需打开该服务的接口文档，对照返回示例把这一行改掉即可（`url:` → 图片链接，`b64:` → base64 文本）。

## 三、用「兼容 OpenAI Images API」通道（如果你手上有这类服务）

| 字段 | 填什么 |
|---|---|
| **服务地址** | 填到 `/v1` 为止，例如 `https://api.example.com/v1`（软件会自己拼 `/images/generations`） |
| **模型名** | 该服务的图片模型名（不确定就留空，用服务默认） |
| **API Key** | 该服务的 Key |

- 点「检查配置」→ 软件会请求 `{地址}/models`：成功会**列出可选模型名**；返回 401/403 说明 Key 不对
- 如果该服务没有 `/models` 端点，会如实告诉你"这在很多服务上正常，建议直接小尺寸生成一张验证"
- 负向提示词会按该 API 惯例**并入 prompt**（`…\n\nNegative prompt: …`），因为标准 Images API 没有负向字段

## 四、怎么"测试"，以及每种提示的含义

| 现象 | 含义 / 怎么办 |
|---|---|
| 「检查配置」显示"连不上：…（确认 WebUI 已启动且地址端口正确）" | 本地通道专用提示。**没装 SD WebUI 就换云端通道**（面板里也会这么提示你） |
| 「检查配置」显示"地址与鉴权均可用，可选模型：…" | 云端 OpenAI 形态连通且 Key 正确 |
| 「检查配置」显示"配置齐了（…避免误触计费）" | 自定义形态的配置完整（此形态**故意不替你发请求**，免得白白扣费） |
| 生成时显示 `服务返回 HTTP 401：…` | Key 错或没保存。回面板把 Key 填好并点「保存到配置」 |
| 显示 `服务返回 HTTP 402/403/429：…` | 余额/权限/限流问题，看服务返回的原文（软件会原样带出来） |
| 显示 `响应里找不到路径「…」` | **响应字段路径填错了**。拿服务文档里的返回示例对照着改（`url:` 表示那个字段是图片链接，`b64:` 表示是 base64 文本） |
| 显示 `下载图片返回 HTTP …` | 图片链接需要鉴权或已过期（有些服务链接只活 1 小时） |
| 显示 `已入库 0/1 张` | 图下来了但入库失败，看消息区里的详细错误 |

**不用真花钱也能验证接线是否正确**：把「张数」设成 1、尺寸设小一点（如 `1024x1024`），先生成一张看看效果。

## 五、想用本地服务的话（可选）

1. 装 [Stable Diffusion WebUI](https://github.com/AUTOMATIC1111/stable-diffusion-webui)（或 ComfyUI，后者软件暂未适配）
2. 启动时**必须带 `--api`**，例如：
   ```
   ./webui.bat --api --listen
   ```
3. 软件里通道选「本地 SD WebUI」，地址默认 `http://127.0.0.1:7860`，点「测试连接」
   → 成功会显示"已连上 SD WebUI，当前模型：xxx"
4. 建议显存 ≥ 8G；无独显用 CPU 也能跑但每张要几分钟

---

## 六、出图之后

- 图会**自动进素材库**并（若选了角色）绑定该角色 → 角色管理里立刻能看到
- 素材库里可以：绑定/解绑、分组、打标签、设为主图、查看版本、导出、删除
- 来源会标成 `AI·本地` / `AI·云端`（素材库只记"来源标记"，不关心谁生成的）

**注意**：每条生成结果都会进素材库（包括你不满意的）。不满意的直接在素材库里删掉即可。

## 七、合规：AI 生成内容的标识义务（请务必看）

参考：《人工智能生成合成内容标识办法》（国家网信办等四部门，**2025-09-01 施行**）
与配套强制性国家标准《网络安全技术 人工智能生成合成内容标识方法》。

### 法规要求的两类标识

| 标识 | 是什么 | 谁加 |
|---|---|---|
| **显式标识** | 用户能明显感知的标识（如"AI 生成"字样 / 水印） | 生成服务提供者 |
| **隐式标识** | 写在文件元数据里的技术标识（不易被感知） | 生成服务提供者 |

> 办法明确：**任何组织和个人不得恶意删除、篡改、伪造、隐匿**本办法规定的生成合成内容标识，
> 不得为他人实施上述恶意行为提供工具或者服务。

### 这对你意味着什么

1. **不要用请求头或参数去关掉服务方加的水印** —— 那属于删除标识，法律风险落在使用者身上
2. **不要把"AI 生成"字样裁掉后对外发布**
3. **本软件不剥离标识**：生成结果走字节流直通（base64 解码 → 原样写临时文件 → 素材库字节拷贝入库，
   全程不重编码），服务方写入的水印与元数据都原样保留 —— 有单测锁住这一点
   （`image_bytes_pass_through_without_stripping_metadata`）
4. **对外发布时请自行标注"AI 生成"**（社交平台、作品插画、商用物料等）：这是使用者义务
5. 自用（自己看、给小说配图存档）通常不涉及传播，但仍不建议去除标识

### 另外两条容易踩的

| 事项 | 说明 |
|---|---|
| **人格权 / 肖像权** | 不要用真人姓名或指向特定真人的照片去"生成某人"的形象；提示词写真实公众人物名字并生成、传播，风险很高 |
| **著作权归属** | AI 生成图的著作权在司法实践中仍有分歧（**人类有独创性智力投入**的情形更容易被认定为作品）。商用建议保留**提示词与参数**作为创作过程证据 —— 本软件已自动把提示词 / 负向 / 种子 / 步数 / CFG 记进素材库 |
| **服务条款** | 你用的是自己申请的 API Key，须同时遵守该服务方的用户协议与内容规范 |
